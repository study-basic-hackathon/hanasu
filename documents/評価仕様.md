# 評価仕様

## 1. 本書の位置づけ

**話の速さ・フィラーの数・構成・内容の項目別スコアと、総合スコアの算出規則を定める。** 評価 API、評価結果を表示する画面、定量スコアを算出するクライアントは本書を正本とする。

評価指標と算出責務の分担は [ADR-0009](ADR/0009-評価方式.md)、点数化基準を選んだ理由は [ADR-0020](ADR/0020-定量スコアの点数化基準.md) にある。

### 本書で決めないこと

| 決めないこと | 扱う場所 |
|---|---|
| 構成・内容を LLM が評価する方法 | 評価 API の実装・プロンプト |
| AmiVoice がフィラーとして返す語の範囲 | [ADR-0010](ADR/0010-音声認識とLLMの基盤選定.md) と音声認識 API の実装 |
| 「間の長さ」の点数化基準 | 実装すると決めた時点の検討 |
| スコアの色・バー・文言 | [画面共通仕様](frontend/01_design/screen_common.md) と各画面仕様 |

## 2. 評価項目と算出者

**基本項目は「話の速さ」「フィラーの数」「構成・内容」の3つとする。**

| 項目 | `scores` のキー | 項目別スコアの算出者 | 算出方法 |
|---|---|---|---|
| 話の速さ | `speaking_speed` | クライアント | 音声回答の文字数と時間を集計し、4章の基準で点数化する |
| フィラーの数 | `filler` | クライアント | 音声回答のフィラー数と時間を集計し、4章の基準で点数化する |
| 構成・内容 | `structure_content` | LLM | 定量の実測値・スコアを受け取らず、会話内容だけを定性評価する |

**総合スコアは、構成・内容の評価が終わった後にバックエンドが算出する**（5章）。

## 3. 定量指標の実測値

### 3.1 共通の集計規則

- **音声で入力したユーザー回答だけ**を定量評価の候補とする。文字入力は話速・フィラーのどちらにも含めない。
- 指標ごとに必要な値が揃っている回答だけを対象とする。対象外の回答は分子・分母のどちらにも含めない。
- 音声認識 API が返す回答ごとの `chars`、`filler_count`、`duration_ms` を合算する。表示用に丸められた `chars_per_min` と `filler_count_per_min` を平均したり、点数化へ使ったりしない。
- 複数の対象回答がある場合は、回答ごとの毎分値を平均せず、**値の合計を時間の合計で割る**。
- 実測値は丸めずに点数化へ渡す。画面表示用の丸めは点数へ影響させない。
- 対象回答が1件もなければ、その項目のスコアを作らない。0点として扱わない。

### 3.2 話の速さ

対象回答は、次の値を取得できた音声回答とする。

- `duration_ms` が0より大きい
- フィラートークンを除去した `clean_transcript` の文字数を取得できる

文字数は `clean_transcript` の先頭と末尾の空白を除いた後の文字数とし、文中の空白・句読点を含める。フィラートークンそのものは含めない。

```text
話速（文字/分） = 対象回答の文字数合計 × 60,000 ÷ 対象回答の duration_ms 合計
```

文字数が0であっても、`duration_ms` を取得できていれば対象回答とし、話速は0文字/分とする。

### 3.3 フィラー

対象回答は、次の値を取得できた音声回答とする。

- `duration_ms` が0より大きい
- `filler_count` を取得できる（0回を含む）

```text
フィラー（回/分） = 対象回答の filler_count 合計 × 60,000 ÷ 対象回答の duration_ms 合計
```

**「1回答あたり」の基準へは切り替えない。** 文字入力、時間を取得できない音声回答、フィラー数を取得できない音声回答は、フィラーの集計から除外する。

## 4. 項目別スコア

### 4.1 共通の点数化規則

- 各基準点の間は、丸め前の実測値を使って線形補間する。
- 満点域と上下限は表の点数へ固定する。
- 補間後の点数を四捨五入し、0〜100の整数とする。0.5は1へ切り上げる。
- 負の実測値は無効とし、その項目の算出には使わない。

基準点 `(x1, y1)` と `(x2, y2)` の間は次の式で求める。

```text
点数 = y1 + (実測値 - x1) × (y2 - y1) ÷ (x2 - x1)
```

### 4.2 フィラー

| 実測値 | 点数 |
|---:|---:|
| 2回/分以下 | 100点 |
| 5回/分 | 50点 |
| 10回/分 | 20点 |
| 15回/分以上 | 0点 |

2〜5回/分、5〜10回/分、10〜15回/分の各区間を線形補間する。

### 4.3 話の速さ

| 実測値 | 点数 |
|---:|---:|
| 0文字/分 | 0点 |
| 100文字/分 | 50点 |
| 200〜250文字/分 | 100点 |
| 350文字/分 | 70点 |
| 400文字/分 | 40点 |
| 500文字/分以上 | 10点 |

0〜100文字/分、100〜200文字/分、250〜350文字/分、350〜400文字/分、400〜500文字/分の各区間を線形補間する。

### 4.4 算出例

| 条件 | 実測値 | 点数 |
|---|---:|---:|
| 話速284文字/分 | 284文字/分 | 90点 |
| 30秒の音声でフィラー2回 | 4回/分 | 67点 |
| 60秒の音声でフィラー2回 | 2回/分 | 100点 |

## 5. 総合スコア

- 算出者はバックエンドとする。
- `speaking_speed`、`filler`、`structure_content` のうち、**存在する項目別スコアだけ**を同じ重みで平均する。
- 計測できずに省略された項目は、合計にも項目数にも含めない。
- 平均値を四捨五入し、0〜100の整数とする。0.5は1へ切り上げる。
- 任意指標の `pause` が存在しても、総合スコアには含めない。
- 基本3項目が1つも存在しない場合は、総合スコアを作らない。

```text
総合スコア = 四捨五入（存在する基本項目の点数合計 ÷ 存在する基本項目数）
```

たとえば話速90点、フィラー80点、構成・内容70点なら総合80点となる。話速を計測できず、フィラー80点と構成・内容70点だけなら総合75点となる。

## 6. 計測対象がない項目の扱い

- 評価 API の `scores` には、計測対象がない定量項目のキーを含めない。
- 結果画面は項目の場所を維持し、スコアを `—`、実測値を `計測対象外` と表示して、バーを塗らない。
- 総合スコアと合否の目安は、5章に従って存在する基本項目から算出・表示する。

## 7. 適用範囲

本仕様を実装した後に新しく作成する評価へ適用する。会話履歴・音声・文字起こしを保存していないため、保存済みの評価結果は再計算しない。
