# ADR-0022: 音声入力モードは常時録音し、無音の長さで発話を区切ってターンを確定する

- ステータス: 決定
- 日付: 2026-08-29
- 依存:

  - [ADR-0008 会話用APIの構成](0008-会話用APIの構成.md) — サーバーが会話状態を持たず、履歴を毎ターン送る前提を引き継ぐ
  - [ADR-0010 音声認識とLLMの基盤選定](0010-音声認識とLLMの基盤選定.md) — AmiVoice は1リクエスト＝1音声ファイルの同期 API である
- 被依存: [#186](https://github.com/study-basic-hackathon/hanasu/issues/186) 自然な会話のような対話形式にする

## コンテキスト(背景と課題)

音声入力モードは「録音を開始する → 話す → 停止して送信する」という一問一答だった。ボタンを押してから話す形は面接の練習として不自然で、利用者は毎ターン操作を求められていた。面接が始まったあとは録音しっぱなしにして、話し終えたら面接官が答える形にしたい。

一方で、常時録音には次の制約がある。

- **AmiVoice は1リクエスト＝1音声ファイルの同期 API である。** 逐次の文字起こしを受け取る口がなく、音声を送るには「どこかで区切る」必要がある
- **面接官の発言はスピーカーから鳴る。** 拾ってしまうと、面接官の声を利用者の回答として文字起こししてしまう
- **`POST /interviews/chat` は質問と回答が交互に並ぶ前提でターンを数える。** 面接官の返答前に回答が2つ積まれると、残りターン数の計算と進捗の表示がずれる

## 決定

- **音声入力モードでは、面接のあいだマイクを開いたままにする。** 録音の開始・停止の操作は持たない
- **無音が一定の長さ続いたところを発話の終わりとみなし、そこまでを1ターンの回答として送る。** 区切った音声はこれまでどおり `POST /interviews/stt` へ1ファイルとして送る
- **面接官の番のあいだはマイクを止める。** 文字起こし中・返答の生成中・読み上げ中のすべてを含み、読み上げが終わったら自動で聞き取りへ戻る。**バージイン（面接官の発言を遮って話す）は行わない**
- **短すぎる発話と、文字が起きなかった区間は捨てて聞き直す。** 会話へ積まず、会話 API も呼ばない
- **無音の長さと入力感度は面接中に変えられる。** 既定値は無音2秒。設定はその面接のあいだだけ有効とし、保存しない
- **文字入力モードは変えない。** 常時録音は音声入力モードだけの振る舞いである

## 検討した選択肢

- 発話の区切り: **A案 無音の長さで区切って即座に返答（採用）** / B案 LLM に「話の途中か」を判定させて待つ / C案 ストリーミング音声認識へ移行する
- 面接官の発話中のマイク: **A案 マイクを止める（採用）** / B案 録音は続けて区間を捨てる / C案 バージインを許す

## 決定要因

- AmiVoice の同期 API と、既存の話速・フィラー算出をそのまま使えること
- 質問と回答が交互に並ぶ前提を保ち、バックエンドを変えずに済むこと
- スピーカー利用でも面接官の声を誤って回答にしないこと
- ハッカソン期間内に収まる実装量であること

## 理由

- **無音の長さで区切る（A案）**: 区切ったファイルをそのまま送れるため、`POST /interviews/stt` も話速・フィラーの算出も現行のまま使える。利用者から見た変化は「押す操作がなくなること」だけで、会話の形は変わらない。
- **LLM の判定を見送る（B案）**: 1発話ごとに追加の LLM 往復が要り、応答が遅くなる。さらに1ターンに複数の回答が並ぶため、`current_turn` の計算とターン進捗の表示を作り直すことになる。
- **ストリーミングを見送る（C案）**: 体験は最も自然になるが、バックエンドに WebSocket の中継を足し、ALB と ECS の設定も変えることになる。ADR-0010 の選定にも踏み込むため、期間内の変更としては大きい。
- **面接官の発話中はマイクを止める（A案）**: エコーキャンセルはブラウザと機材に依存し、スピーカー利用では面接官の声を拾う。録音を続けて区間を捨てる方法（B案）では、エコーが次の発話の頭に残る余地がある。バージイン（C案）は自分のスピーカー音で誤って発話と判定され、面接官が黙る誤作動を招く。
- **短い発話と空の文字起こしを捨てる**: 常時録音では咳・物音・独り言も区間として成立する。これらを回答として積むと、面接官が中身のない発言に返答してしまう。
