# 共通仕様

## 1. 本書の位置づけ

**全画面に共通する振る舞いと、画面をまたいで使う表示のきまりを定める。** 画面ごとに変わる内容は [画面詳細仕様](screens/) が持ち、本書は「どの画面でも同じもの」だけを扱う。

**見た目の正本は [デザイン原本](screen_design.html) である。** 本書に載せる寸法・配色は、実装のたびに原本を開かなくて済むよう抜き出した基本値であり、個々の画面の余白や文字サイズまでは定めない。

**ただし文言・画面名・表示項目は本書と [画面詳細仕様](screens/) が正本である。** デザイン原本は本書群の内容に合わせてあるが、両者が食い違ったときは本書群を採る。

### 本書で決めないこと

| 決めないこと | 扱う場所 |
|---|---|
| 画面ごとの表示項目・入力・状態 | [画面詳細仕様](screens/) の各画面 |
| 画面の一覧と役割 | [画面一覧](screen_list.md) |
| 画面と画面のつながり | [画面遷移図](screen_flow.md) |
| 各画面が呼ぶ API | [画面と API の対応](screen_api_map.md) |
| API の入出力 | [API仕様.md](../../backend/API仕様.md) |
| UI ライブラリ・デザイントークン・共通部品の実装方針 | [ADR-0014](../../ADR/0014-UI技術方針.md) |

| 最小幅 | **1280px**。これを下回る幅では横スクロールを許容し、レイアウトを組み替えない |

**カード（白い面）を基本単位とする。** 背景 `#fff`、枠線 1px `#e2e5e8`、角丸 6px。

## 4. グローバルヘッダー

**S-04・S-05・S-06・S-07・S-14・S-16 が持つ。** 高さ 60px、背景 `#fff`、下線 1px `#e2e5e8`、左右余白 32px。**画面をスクロールしても位置を保つ。**

| 位置 | 要素 | 挙動 |
|---|---|---|
| 左 | ロゴ「hanasu」 | 押すと S-04 へ |
| 左（ロゴの右） | ナビ4項目 | 下表のとおり |
| 右 | サインイン中の ID（例: `user01`） | 表示のみ。押しても何も起きない |
| 右端 | 「サインアウト」ボタン | [6.3 サインアウト](#63-サインアウト) |

### 4.1 ナビ

| ラベル | 遷移先 | 対応する画面 |
|---|---|---|
| ホーム | S-04 | S-04 |
| 応募先企業 | S-06 | S-06、S-07 |
| 履歴 | S-16 | S-16、S-14 |

**「対応する画面」を表示しているあいだ、そのラベルを現在地として強調する**（文字色 `#0f766e`・太字・下線 2px）。それ以外は `#5c666e`。

**S-07 では「応募先企業」を、S-14 では「履歴」を現在地とする。** どちらもナビから直接は開けない画面だが、系統としてそこに属するためである。

**S-05 と練習モード（S-09）へはナビから直接入れず、S-04 の2ボタンからモードを固定した S-05 へ入る。**

## 5. 専用ヘッダー

**S-08・S-09・S-10〜S-13 はグローバルヘッダーを持たない。** 会話や練習の最中にナビを置かず、離脱の導線だけを残す。

| 画面 | 高さ | 左 | 右 |
|---|---|---|---|
| S-08 本番モード | 60px | ロゴ + 「本番モード」 | 常時「ホーム」。ターン上限前は「中断」も表示 |
| S-09 練習モード | 60px | ロゴ + 「練習モード」 | 「設定に戻る」（→ `/practice/setup?mode=practice`） |
| S-10〜S-13 練習のサブ機能 | 48px | 画面 ID + 画面名 | 「別の練習を選ぶ」 |

**S-01 サインインはヘッダーを持たない。**

**S-08 はヘッダーの下にさらに実施条件の帯（高さ 52px）を持つ**（[S-08 の詳細仕様](screens/S-08_本番モード.md)）。

## 6. 認証

### 6.1 未認証のとき

**アクセストークンを持たない状態で S-01 以外を開いたときは、S-01 へ移す。** 元の画面は覚えず、サインイン後は必ず S-04 へ入る。

### 6.2 トークンが失効したとき

**API が 401 を返したときは、保持しているトークンを破棄して S-01 へ移す。** 画面には「サインインの有効期限が切れました。もう一度サインインしてください。」と示す。

**S-08 で 401 を受けたときも同じ扱いとする。** 会話履歴はクライアントが持っているだけなので失われる（[7.3](#73-会話中の離脱)）。

### 6.3 サインアウト

**トークンを破棄して S-01 へ移す。** サインアウト API は呼ばない。**確認は挟まない。**

**ただし S-08 の最中はサインアウトできない。** S-08 はグローバルヘッダーを持たないため、先に「中断」または「ホーム」を選ぶか、ブラウザを離れることになる。

## 7. 状態の表示

### 7.1 読み込み中

| 対象 | 表示 |
|---|---|
| 画面を開いたときのデータ取得 | **カードの形を保ったまま、中身を灰色の帯に置き換える**（スケルトン）。画面全体を覆う表示は使わない |
| ボタンを押した後の処理（保存・削除・送信） | **そのボタンを押せなくし、ラベルを処理中の文言に替える**（例: 「保存する」→「保存しています」）。画面はそのまま |
| 評価の完了待ち | S-14 の専用表示（[S-14 の詳細仕様](screens/S-14_評価.md)） |

**200ms 未満で終わる処理には読み込み表示を出さない。** 一瞬だけ現れて消える表示は、かえって画面が不安定に見えるためである。

### 7.2 エラー

| 種類 | 表示 | 復帰の手段 |
|---|---|---|
| **通信・サーバーエラー**（5xx、ネットワーク断） | 対象のカードの中に、見出し「読み込めませんでした」・原因の短い説明・「再読み込み」ボタンを出す | 再読み込み |
| **操作の失敗**（保存・削除の失敗） | 操作したカードの上部に赤字（`#b3261e`）で1行示す。**入力内容は消さない** | もう一度実行する |
| **入力の誤り**（バリデーション） | 該当の入力欄を赤枠にし、欄の直下に赤字で理由を示す | 入力を直す |
| **認証切れ**（401） | [6.2](#62-トークンが失効したとき) | サインインし直す |
| **評価の失敗**（`failed`） | S-14 の専用表示（[S-14 の詳細仕様](screens/S-14_評価.md)） | 評価をやり直す |

**エラーの文言に技術的な内容（ステータスコード・例外名）を出さない。**

### 7.3 会話中の離脱

**S-08 は会話履歴をクライアントだけが持つ**（[ADR-0008](../../ADR/0008-会話用APIの構成.md)）。そのため次のとおり扱う。

| 事象 | 扱い |
|---|---|
| 回答済みでブラウザを再読み込み・タブを閉じる | **ブラウザの標準の確認ダイアログを出す。** 続行された場合、会話は失われる |
| 「中断」 | 確認を挟んでから S-14 へ。**確認は「評価に進みます。この会話には戻れません。」** |
| 回答0件で「ホーム」 | 確認を挟まず、評価 API を呼ばずに S-04 へ |
| 回答済みで「ホーム」 | **「ホームに戻ると、この会話は失われます。評価は行われません。」と確認する。** 取り消した場合は会話を保持して S-08 に留まり、続行した場合は評価 API を呼ばずに S-04 へ |
| 会話が失われたあとの復帰 | **持たない。** S-04 から入り直す |

**S-08 の画面下部に「この画面を離れると会話は失われます。評価は『中断』を押したあとに行われます。」を常に表示する。** ターン上限到達後は操作名を「評価を見る」に替える。

## 8. マイクの使用許可

| 時点 | 挙動 |
|---|---|
| S-05 で回答方式に「音声入力」を選んだとき | **許可は求めない。** 「音声入力を選ぶとマイクの使用許可を求めます。」とだけ示す |
| **音声入力モードの S-08 を開いたとき** | **ブラウザに許可を求める。** 常時録音のため、画面表示が最初の録音になる（[ADR-0022](../../ADR/0022-音声入力モードの常時録音と発話の区切り.md)） |
| 許可されたとき | **そのまま面接のあいだ録音し続ける。** 面接官が話しているあいだと返事を待っているあいだは止める |
| **拒否されたとき** | **マイクのボタンを押せなくし、「マイクを使えません。ブラウザの設定で許可するか、文字入力モードで始め直してください。」と示す。あわせて「文字入力モードで始め直す」を出す** |
| マイクが見つからないとき | 拒否されたときと同じ扱い |

**拒否されても会話は終わらせない。** ただし回答方式は画面の中で切り替えられないため、**「文字入力モードで始め直す」は会話を破棄して同じ設定の文字入力ページを開き直す**。押したときは会話が失われ評価されないことを確認する（7.3）。

## 9. スコアの表示

**総合スコア・項目別スコアはいずれも 0〜100 の整数**（[評価仕様](../../評価仕様.md)）。**S-04・S-14・S-16 で同じ見え方にする。**

| 範囲 | 意味 | 色 |
|---|---|---|
| 65〜100 | 良好 | `#0f766e` |
| 45〜64 | 注意 | `#c47f0f` |
| 0〜44 | 要改善 | `#b3261e` |

**バーの長さはスコアをそのまま百分率にする**（72点 → 72%）。バーの下地は `#e7eaec`。

**総合スコアには色をつけない。** 項目別スコアだけを色分けし、総合スコアは数値と円グラフで示す。

**計測対象がない項目は、スコアを `—`、実測値を `計測対象外` とし、バーの下地だけを表示する。** 0点として色を付けたり、バーを0%として評価したりしない。総合スコアは [評価仕様](../../評価仕様.md) に従い、存在する基本項目だけから算出された値を表示する。

## 10. 表記

| 対象 | 書式 | 例 |
|---|---|---|
| 日時（一覧・詳細） | `YYYY-MM-DD HH:mm` | `2026-08-17 21:14` |
| 会話中の時刻 | `HH:mm` | `21:04` |
| 録音・経過時間 | `mm:ss` | `00:18` |
| 話す速さ | `<整数> 文字/分` | `284 文字/分` |
| フィラー（S-04・S-14 の実測値） | `<小数第1位> 回/分` | `2.1 回/分` |
| 件数 | `<整数> 件` | `12 件` |

**時刻はブラウザのタイムゾーンで表示する。**
