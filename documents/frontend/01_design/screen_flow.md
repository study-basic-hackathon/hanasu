## 1. 本書の位置づけ

**[画面一覧](screen_list.md) が定めた14画面について、どの操作でどの画面へ移るかを定める。** 各画面の役割・表示情報は画面一覧が持ち、本書は遷移だけを扱う。

未認証状態でのリダイレクト、エラー時の画面、ローディング中の表示といった全画面に共通する挙動は本書の対象外で、[#9](https://github.com/study-basic-hackathon/hanasu/issues/9) の共通仕様で定める。

**S-02 / S-15 は欠番のため本書には現れない**（[画面一覧](screen_list.md) 4章）。

## 2. 全体の画面遷移図

```mermaid
flowchart TD
    S01["S-01 サインイン"]
    S03["S-03 チュートリアル<br/>(S-08 の画面を流用)"]
    S04["S-04 ホーム"]
    S05["S-05 モード選択"]
    S06["S-06 応募企業情報 一覧"]
    S07["S-07 応募企業情報 登録 / 編集"]
    S08["S-08 実践 - 本番モード"]
    S09["S-09 実践 - 練習モード"]
    S14["S-14 評価 - 合否判定"]
    S16["S-16 履歴一覧"]

    subgraph practice["練習のサブ機能（画面モックのみ）"]
        S10["S-10 音読評価"]
        S11["S-11 滑舌練習"]
        S12["S-12 スピード測定"]
        S13["S-13 一問一答評価"]
    end

    S01 -->|サインイン| S04

    S04 -->|実践を始める| S05
    S04 -->|チュートリアルを試す| S03
    S04 -->|応募企業情報を見る| S06
    S04 -->|履歴を見る| S16

    S03 -->|終える| S14

    S05 -->|企業を追加| S07
    S05 -->|本番モードで開始| S08
    S05 -->|練習モードで開始| S09

    S06 -->|追加 / 編集| S07
    S06 -->|戻る| S04
    S07 -->|保存 / 取り消し| S05
    S07 -->|保存 / 取り消し| S06

    S08 -->|面接終了| S14
    S09 -->|サブ機能を選ぶ| practice
    practice -->|終了| S14
    practice -->|別の練習を選ぶ| S09

    S14 -->|再挑戦| S05
    S14 -->|本番の準備をする| S07
    S14 -->|ホームへ| S04
    S16 -->|結果を開く| S14
```

## 3. 遷移一覧

| # | 遷移元 | 遷移先 | 契機 | 備考 |
|---:|---|---|---|---|
| 1 | S-01 サインイン | S-04 ホーム | サインインに成功した | **唯一の入口。** 会員登録の導線は持たない（[ADR-0011](../../ADR/0011-会員登録と利用アカウント.md)） |
| 2 | S-04 ホーム | S-05 モード選択 | 「実践を始める」を選んだ | 主導線 |
| 3 | S-04 ホーム | S-03 チュートリアル | チュートリアルを試すことを選んだ | **必須ではない。** 応募企業情報が未登録でも入れる |
| 4 | S-04 ホーム | S-06 応募企業情報 一覧 | 登録済みの応募企業情報を見ることを選んだ | |
| 5 | S-04 ホーム | S-16 履歴一覧 | 過去の結果を見ることを選んだ | |
| 6 | S-03 チュートリアル | S-14 評価 | 自己紹介1問に回答し終えた | |
| 7 | S-05 モード選択 | S-07 応募企業情報 登録 / 編集 | 「企業を追加」を選んだ | 登録済みが0件のときは追加を促す |
| 8 | S-05 モード選択 | S-08 本番モード | 本番モードを選んで開始した | 企業未選択では開始できない |
| 9 | S-05 モード選択 | S-09 練習モード | 練習モードを選んで開始した | **モックのため実際の練習は行わない** |
| 10 | S-06 応募企業情報 一覧 | S-07 応募企業情報 登録 / 編集 | 追加または編集を選んだ | 削除は S-06 内で完結する |
| 11 | S-06 応募企業情報 一覧 | S-04 ホーム | 戻ることを選んだ | |
| 12 | S-07 応募企業情報 登録 / 編集 | 呼び出し元（S-05 / S-06 / S-14） | 保存した、または取り消した | 呼び出し元へ戻る |
| 13 | S-08 本番モード | S-14 評価 | 面接を終える操作をした、または**画面が持つターン数の上限に達した** | **サーバーは終了を判断しない**（[ADR-0008](../../ADR/0008-会話用APIの構成.md)） |
| 14 | S-09 練習モード | S-10〜S-13 | サブ機能を選んだ | **モックのみ** |
| 15 | S-10〜S-13 練習のサブ機能 | S-14 評価 | 練習を終えた | **モックのみ** |
| 16 | S-10〜S-13 練習のサブ機能 | S-09 練習モード | 別の練習を続けることを選んだ | **モックのみ** |
| 17 | S-14 評価 | S-05 モード選択 | 再挑戦を選んだ | UC-09 に対応 |
| 18 | S-14 評価 | S-07 応募企業情報 登録 / 編集 | 本番の準備をすることを選んだ | **チュートリアル直後の導線。** 応募企業情報が0件のときに出す |
| 19 | S-14 評価 | S-04 ホーム | ホームに戻ることを選んだ | |
| 20 | S-16 履歴一覧 | S-14 評価 | 過去の結果を開いた | 評価画面を再表示する |

## 4. 前版から変わった遷移

**2026-08-13 版から、[ADR-0011](../../ADR/0011-会員登録と利用アカウント.md) とチーム会議の決定を受けて次の遷移を変更した。**

| 前版の遷移 | 変更 |
|---|---|
| S-01 →（新規登録）→ S-02 プロフィール登録 → S-03 チュートリアル | **削除。** 会員登録もプロフィール登録も持たないため、サインイン後は必ず S-04 へ入る |
| S-03 チュートリアル → S-04 ホーム | **S-14 評価へ変更。** チュートリアルは自己紹介1問への評価を返すもので、初期スコアを記録して戻る位置づけではなくなった |
| S-04 ホーム → S-15 プロフィール編集 | **削除**（S-15 は欠番） |
| S-04 ホーム →（**将来対応**）→ S-16 履歴一覧 | **今回作る。** 点線から実線へ |
| （なし） | **S-14 → S-07 を追加。** チュートリアル直後に本番の準備へ進む導線（[ユースケース](../../ユースケース・ユーザーフロー.md) 6.1） |
