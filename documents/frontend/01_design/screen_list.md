# 画面一覧

## 1. 本書の位置づけ

**本サービスが持つ画面をすべて列挙し、各画面の役割と主な表示情報を定める。** [ユースケース・ユーザーフロー.md](../../ユースケース・ユーザーフロー.md) が定めた「機能とその順序」を、何画面でどう見せるかに落としたものである。画面と画面のつながりは [画面遷移図](screen_flow.md) が担う。

### 本書で決めないこと

| 決めないこと | 扱う場所 |
|---|---|
| 各画面の詳細仕様（表示項目・入力・状態・バリデーション） | [画面詳細仕様](screens/) の各画面 |
| 全画面に共通する仕様（グローバルヘッダー、未認証時のリダイレクト、エラー表示、ローディング表示、マイク許可が拒否された場合の挙動） | [共通仕様](screen_common.md) |
| 画面と API の対応 | [画面と API の対応](screen_api_map.md) |
| 見た目（寸法・配色・余白・文字サイズ） | [デザイン原本](screen_design.html)。抜粋した基本値は [共通仕様](screen_common.md) |
| UI ライブラリ・デザイントークン・共通部品の実装方針 | [ADR-0014](../../ADR/0014-UI技術方針.md) |
| 応募企業情報の各項目の型・制約 | [API仕様](../../backend/API仕様.md) 4章 |

## 2. 前提

| # | 前提 | 出典 |
|---:|---|---|
| 1 | **PC のブラウザで利用する。** スマートフォン向けのレイアウトは持たない。**基準幅は 1440px** | [ユースケース](../../ユースケース・ユーザーフロー.md) 前提1 / [共通仕様](screen_common.md) |
| 2 | 認証済みユーザーのみが利用できる | 同 前提2 / [API仕様.md](../../backend/API仕様.md) 1. 共通事項 |
| 3 | **会員登録は作らない。** 固定の ID / パスワード1組でログインし、**ユーザーは1つだけ** | [ADR-0011](../../ADR/0011-会員登録と利用アカウント.md) |
| 4 | **プロフィールという独立した登録を持たない。** 応募者自身の情報は応募企業情報に含める | [ユースケース](../../ユースケース・ユーザーフロー.md) 2.2 |
| 5 | **練習モードは画面のモックのみ作る** | 同上 |
| 6 | **評価指標は話の速さ・フィラーの数・構成/内容の3つ**（任意で間の長さ）。**「抑揚」「滑舌」「声の大きさ」は評価しない** | [ADR-0009](../../ADR/0009-評価方式.md) |
| 7 | **評価は非同期。** 結果が出るまで画面がポーリングする | [ADR-0008](../../ADR/0008-会話用APIの構成.md) |

**対応デバイスは PC のみとする。**

### 画面をまたぐ扱い

| 事項 | 扱い |
|---|---|
| **グローバルヘッダー** | **S-04・S-05・S-06・S-07・S-14・S-16 が共通のヘッダーを持つ。** ナビは4項目（ホーム / 応募先企業 / 履歴 / 練習の設定）。「練習の設定」はモード未確定のため S-04 を開き、それ以外は S-04 / S-06 / S-16 へ移る。**サインアウトもヘッダーに置く**（[共通仕様](screen_common.md)） |
| **ヘッダーを持たない画面** | **S-01 はヘッダーを持たない。S-08・S-09〜S-13 はグローバルヘッダーの代わりに専用のヘッダーを持つ**（ロゴ・画面名・離脱の導線のみ）。会話や練習から注意をそらさないため |
| **ナビのラベルと画面名** | **ナビ「応募先企業」は画面名（応募企業情報 一覧）と表記が異なる。ナビ「練習の設定」は S-05 を直接開かず、モード選択のため S-04 を開く。** ラベルは [共通仕様](screen_common.md)、画面名は本書が正本 |
| サインインと会員登録 | **会員登録の画面を持たない。** S-01 はサインインのみ（[ADR-0011](../../ADR/0011-会員登録と利用アカウント.md)） |
| チュートリアルと本番モード | **S-08 の画面を流用する。** 質問が1問に固定され、応募企業情報を使わない点だけが異なる |
| 応募企業情報の登録と編集 | **1画面（S-07）を兼用する。** 入力項目が同じため。削除は S-06 の一覧から行う |
| 本番モードとチュートリアルの評価 | **共通の1画面（S-14）を使う。** 総合スコア・項目別スコアという構造が共通で、中身だけが変わる。**練習モード（S-09〜S-13）はモックのため評価を行わず、S-14 を使わない** |
| 履歴の結果詳細 | **S-14 を再表示する。** 表示項目が評価画面と同じため、専用画面は作らない |

**S-02 / S-15 は欠番とする**（[ユースケース](../../ユースケース・ユーザーフロー.md) の UC-02 を欠番としているのと同じ扱い）。

## 4. 今回は持たない画面

| 画面 | 持たない理由 |
|---|---|
| **会員登録** | **固定の ID / パスワード1組で利用するため**（[ADR-0011](../../ADR/0011-会員登録と利用アカウント.md)）。サインアップの API・画面とも作らない |
| パスワード再設定 | 会員登録自体を作らないため。**サインインできなくなった場合の復旧手段は持たない** |
| **プロフィール登録 / 編集** | **応募企業情報（S-07）に集約したため**（[ユースケース](../../ユースケース・ユーザーフロー.md) 2.2）。面接の質問生成に必要な情報は応募する企業ごとに変わるため、1画面にまとめる |
| 設定（ハブ）画面 | プロフィールを独立して持たなくなったことで、**設定項目そのものがなくなった** |
