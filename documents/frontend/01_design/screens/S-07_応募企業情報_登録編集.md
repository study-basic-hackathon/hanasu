# S-07 応募企業情報 登録 / 編集

## 1. 位置づけ

**企業ごとの情報と応募者自身の情報を登録・更新し、面接の質問生成に反映させる。**

| 項目 | 内容 |
|---|---|
| 遷移元 | S-05（企業を追加 / 編集）、S-06（企業を追加 / 編集）、S-04（0件のときの「登録する」） |
| 遷移先 | **呼び出し元へ戻る**（S-05 または S-06。S-04 から来たときは S-06 へ） |
| ヘッダー | グローバル（現在地: **応募先企業**） |
| コンテンツ幅 | 1000px |
| 実装範囲 | 今回 |

**登録と編集で同じ画面を使う**（[画面一覧](../screen_list.md)）。**プロフィールという独立した登録は持たず、応募者自身の情報もこの画面に含める**（[ユースケース](../../../ユースケース・ユーザーフロー.md) 2.2）。

## 2. 画面の構成

**左が可変・右が 300px の2カラム。**

| 領域 | 位置 | 内容 |
|---|---|---|
| 見出し | 最上部 | パンくずと見出し |
| 企業の情報 | 左・上 | 企業名ほか4項目 |
| 応募者自身の情報 | 左・下 | 現職ほか4項目 |
| 操作 | 左・最下部 | 右寄せで `取り消す` と `保存する` |
| 入力のヒント | 右 | 充足度と注記 |

| 状態 | パンくず | 見出し |
|---|---|---|
| 新規登録 | `応募企業情報 / 新規登録` | `新規登録` |
| 編集 | `応募企業情報 / 編集` | **その企業名**（未入力なら `新規登録`） |

## 3. 入力項目

### 3.1 企業の情報

| # | 項目 | 種類 | 必須 | 補足 |
|---:|---|---|---|---|
| 1 | 企業名 | 1行 | **○** | ラベルの右に `必須` を赤字で添える |
| 2 | 募集要項 URL | 1行 | | 求人ページの URL |
| 3 | 職種 | 1行 | | 募集要項 URL と横並び |
| 4 | 応募書類（貼り付け） | 複数行 | | プレースホルダ `職務経歴書の本文をそのまま貼り付けてください。面接官の質問に反映されます。` |
| 5 | 志望動機 | 複数行 | | |

### 3.2 応募者自身の情報

**見出しの下に `プロフィール登録は持たず、応募先ごとに書き分けます。` を添える。**

| # | 項目 | 種類 | 必須 | 補足 |
|---:|---|---|---|---|
| 6 | 現職 / 直近の所属 | 1行 | | 経験年数と横並び |
| 7 | 経験年数 | 数値 | | **0〜99 の整数。** 単位 `年` は画面側で添える |
| 8 | 経歴・実績 | 複数行 | | |
| 9 | 備考 | 複数行 | | プレースホルダ `面接で触れてほしくない話題などがあれば記入してください。` |

**各項目の最大長は [#17](https://github.com/study-basic-hackathon/hanasu/issues/17) で定める**（9章）。

## 4. 入力のヒント（右カラム）

| 項目 | 内容 |
|---|---|
| 見出し | `入力のヒント` |
| 説明 | `埋まっている項目が多いほど、面接官の質問が具体的になります。企業名以外は後から追記できます。` |
| 充足度 | `入力の充足` と `<入力済み> / 8`、その下にバー |
| 未入力の一覧 | `未入力：<項目名を読点で連ねる>`。**すべて入力済みなら出さない** |
| 注記 | `この情報は評価には使われず、質問の生成にのみ使われます。` |

**充足度の分母は、企業名を除く8項目である**（募集要項 URL・職種・応募書類・志望動機・現職 / 直近の所属・経験年数・経歴・実績・備考）。企業名は必須で入力されるため数えない。

**空白だけの入力は未入力として数える。** バーの長さは `入力済み ÷ 8` の百分率とし、入力に応じてその場で更新する。

## 5. バリデーション

| 項目 | 条件 | エラー文 |
|---|---|---|
| 企業名 | 空、または空白だけ | `企業名を入力してください。` |
| 募集要項 URL | `http://` / `https://` で始まらない | `http:// または https:// で始まる URL を入力してください。` |
| 経験年数 | 整数でない、または 0〜99 の外 | `0〜99 の数字で入力してください。` |

**検査は「保存する」を押したときに行う。** 誤りがあれば保存せず、該当の入力欄を赤枠にし、直下に理由を出す（[共通仕様](../screen_common.md) 7.2）。**最初の誤りの位置まで画面を送る。**

**企業名が空のあいだは「保存する」を押せなくする。**

## 6. 操作

| 操作 | 挙動 |
|---|---|
| 「保存する」 | 検査を通れば保存し、**呼び出し元へ戻る** |
| 「取り消す」 | 保存せずに呼び出し元へ戻る。**入力の途中でも確認を出さない** |
| ヘッダーのナビ | 保存せずにその画面へ移る |

**保存に成功したあと、戻り先の画面の上部に `<企業名> を保存しました。` を出す。**

## 7. 状態

| 状態 | 表示 |
|---|---|
| 新規登録 | すべての欄が空。見出しは `新規登録` |
| 編集・読み込み中 | 入力欄をスケルトンにする。**「保存する」は押せない** |
| 保存中 | 「保存する」を押せなくし、ラベルを `保存しています` に替える |
| 保存に失敗 | 操作の並びの上に赤字で `保存できませんでした。時間をおいてもう一度お試しください。` **入力内容は消さない** |
| 取得に失敗（編集） | カードの中に「読み込めませんでした」と「再読み込み」を出す |

## 8. 呼ぶ API

| 契機 | API |
|---|---|
| 編集で開く | 応募企業情報 Read |
| 保存する（新規） | 応募企業情報 Create |
| 保存する（編集） | 応募企業情報 Update |
