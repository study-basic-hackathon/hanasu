# S-14 評価 - 合否判定

## 1. 位置づけ

**練習の結果を総合的に評価し、フィードバックを返す。履歴から過去の結果を開いたときも同じ画面を使う。**

| 項目 | 内容 |
|---|---|
| 遷移元 | S-08（中断 / ターン上限後に評価を見る）、S-03（チュートリアル終了）、S-16（結果を開く）、S-04（詳細を見る） |
| 遷移先 | S-05、S-16、S-04 |
| ヘッダー | グローバル（現在地: **履歴**） |
| コンテンツ幅 | 1080px |
| 実装範囲 | 今回 |

**評価は非同期である。** 実行 API は ID だけを返し、この画面が完了までポーリングする（[ADR-0008](../../../ADR/0008-会話用APIの構成.md)）。

## 2. 画面の状態

**評価の処理状態によって3つの見え方を持つ。**

| 状態 | 見え方 |
|---|---|
| `processing` | [3章 処理中](#3-処理中) |
| `completed` | [4章 結果](#4-結果) |
| `failed` | [5章 失敗](#5-失敗) |

**履歴（S-16）や S-04 から開いたときは、すでに完了しているため 4章の表示から始まる。**

## 3. 処理中

**画面の中央に幅 440px のカードだけを置く。** ヘッダーは通常どおり出す。

| 項目 | 内容 |
|---|---|
| 進捗の円 | 回転する円で待ちを示す |
| 見出し | `評価しています` |
| 説明 | `会話全体を読み込んで評価を作成中です。1分ほどかかります。`<br>`この画面を開いたままお待ちください。` |
| バー | 待ち時間の目安を示す横棒 |

| 項目 | 値 |
|---|---|
| ポーリングの間隔 | **3秒** |
| 打ち切り | **5分**。過ぎたら [5章 失敗](#5-失敗) と同じ表示にし、説明を `時間がかかりすぎたため中断しました。` に替える |

**この画面を離れると評価の結果を受け取れない。** 完了した結果はサーバーに残るため、あとから S-16 で開ける。

## 4. 結果

### 4.1 総合（濃色のカード）

| 項目 | 内容 |
|---|---|
| 総合スコア | 円の内側に数値。**円は総合スコアの割合だけ塗る** |
| ラベル | `総合スコア` |
| 合否の目安 | `合否の目安：<判定>`（[4.2](#42-合否の目安)） |
| 実施条件 | `<対象企業> / 強度 <楽々 / 標準 / 厳しめ / カスタム> / <N> ターン` |
| 操作 | `再挑戦する`（→ `/practice/setup?mode=interview` で S-05）、`履歴`（→ S-16）、`ホームに戻る`（→ S-04） |

**総合スコアには色を付けない**（[共通仕様](../screen_common.md) 9章）。

**対象企業・質問の強度・ターン数は評価結果が持つ**（[画面と API の対応](../screen_api_map.md) 6章）。**履歴から開いた過去の結果でも同じように表示する。**

**前回との差分は表示しない。**

**チュートリアルの結果では、実施条件を `チュートリアル / 1 ターン` とする。**

### 4.2 合否の目安

**API は合否を返さない。総合スコアから画面が決める**（[画面と API の対応](../screen_api_map.md)）。**当面はハードコードとする。**

| 総合スコア | 判定 |
|---|---|
| 65〜100 | `通過見込み` |
| 45〜64 | `あと一歩` |
| 0〜44 | `練習が必要` |

**しきい値は [共通仕様](../screen_common.md) 9章のスコアの色分けと同じにする。**

### 4.3 項目別スコア

**3つのカードを等幅で並べる。** 各カードは点数・実測値・バー・補足からなる。**点数は単位を付けて `72 点` とし、`点` は数値より小さく出す**（[共通仕様](../screen_common.md) 10章）。**実測値は薄い色で点数の右に添える。**

| 項目 | 実測値 | 補足 |
|---|---|---|
| 話の速さ | `<整数> 文字/分` | **100点となる適正域（240〜260 文字/分）との関係を1文で示す** |
| フィラーの数 | `<毎分（小数第1位）> 回/分`（例: `9.0 回/分`） | **補足を持たない** |
| 構成・内容 | `AI 評価` | **サーバーが返した短評をそのまま出す** |

**点数の数値・バーの色は [共通仕様](../screen_common.md) 9章に従う（単位 `点` も数値と同じ色にする）。** 実測値と補足は色を変えない。

**語ごとのフィラーの内訳（`えー 6` など）は表示しない。** 話の速さの補足はクライアントが実測値と適正域から組み立てる。

**話の速さまたはフィラーを計測できない場合も、3つのカードの配置は変えない。** 該当カードは点数を単位なしの `—`、実測値を `計測対象外` とし、バーの下地だけを表示する。補足は `計測できる音声回答がありません。` とする。総合スコアは、計測できた基本項目だけからバックエンドが算出した値を表示する（[評価仕様](../../../評価仕様.md) 5章・6章）。

### 4.4 アドバイス

| 項目 | 内容 |
|---|---|
| 見出し | `アドバイス` |
| 本文 | **サーバーが返した文の並びを、順に段落として出す**（`advice` は文の配列。[API仕様.md](../../../backend/API仕様.md) 5.6） |

### 4.5 免責

**最下部に必ず出す。** `合否の目安は本サービス内の参考値であり、実際の選考結果とは関係ありません。`

## 5. 失敗

**処理中と同じ位置に幅 440px のカードを置く。**

| 項目 | 内容 |
|---|---|
| 記号 | 危険色の `!` |
| 見出し | `評価に失敗しました` |
| 説明 | `会話の内容は保存されています。もう一度評価を実行できます。` |
| 操作 | `評価をやり直す` / `ホームに戻る` |

**「評価をやり直す」は S-08 から続けて開いたときだけ出す。** 会話履歴を持つのはその場合だけだからである（[ADR-0008](../../../ADR/0008-会話用APIの構成.md)）。**履歴から開いた失敗の結果では、説明を `この結果は取得できませんでした。` に替え、`履歴に戻る` だけを出す。**

「評価をやり直す」を押すと `POST /evaluations` をもう一度呼び、[3章 処理中](#3-処理中) に戻る。

## 6. 操作

| 操作 | 遷移先 | 備考 |
|---|---|---|
| 「再挑戦する」 | 本番モード固定の S-05 | `/practice/setup?mode=interview` を開く。**同じ対象企業・強度・回答方式を選んだ状態で開く。** 企業が削除されていたときは未選択で開く |
| 「履歴」 | S-16 | |
| 「ホームに戻る」 | S-04 | |
| 「評価をやり直す」 | — | 同じ画面で処理中に戻る |

## 7. 呼ぶ API

| 契機 | API |
|---|---|
| 画面表示（S-08 から） | `GET /evaluations/{evaluation_id}` を `completed` になるまでポーリング |
| 画面表示（S-16 / S-04 から） | `GET /evaluations/{evaluation_id}` を1回 |
| 評価をやり直す | `POST /evaluations` |
