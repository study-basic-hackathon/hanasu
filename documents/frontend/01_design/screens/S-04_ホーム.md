# S-04 ホーム

## 1. 位置づけ

**サインイン後の起点。本番モード・練習モードの開始導線と、直近の状況をまとめて示す。**

| 項目 | 内容 |
|---|---|
| 遷移元 | S-01（サインイン成功）、S-06（戻る）、S-14（ホームに戻る）、ヘッダーのロゴ / ナビ「ホーム」 |
| 遷移先 | S-05、S-03、S-06、S-16、S-14 |
| ヘッダー | グローバル（現在地: **ホーム**） |
| コンテンツ幅 | 1200px |
| 実装範囲 | 今回 |

## 2. 画面の構成

| 領域 | 位置 | 内容 |
|---|---|---|
| 見出し | 最上部 | 左に `ホーム`、右に最終実施日時 |
| 直近の評価結果 | 上段左 | 総合スコアと項目別スコア、実施条件 |
| 面接・練習を始める | 上段右・上 | **アクセント色で塗ったカード。本番モード・練習モードを選ぶ主導線** |
| チュートリアル | 上段右・下 | 白いカード |
| 応募企業情報 | 下段左 | 登録件数と一覧への導線 |
| 履歴 | 下段右 | 件数と一覧への導線 |

**上段は左が可変・右が 380px の2カラム。下段は等幅の2カラム。**

## 3. 表示項目

### 3.1 見出し

| 項目 | 内容 |
|---|---|
| 見出し | `ホーム` |
| 最終実施日時 | `最終実施 YYYY-MM-DD HH:mm`。**直近の評価結果の実施日時**。結果が0件のときは表示しない |

### 3.2 直近の評価結果

**`GET /evaluations` で得た全件のうち、実施日時が最も新しい1件を表示する。**

| 項目 | 内容 |
|---|---|
| 見出し | `直近の評価結果` |
| 詳細への導線 | `詳細を見る`。押すとその結果を S-14 で開く |
| 総合スコア | 円で示す。**円の内側に数値、その下に `総合スコア`** |
| 項目別スコア | 話の速さ / フィラーの数 / 構成・内容の3件。**各行はラベル・スコア・実測値・バー**（話の速さは `90 / 284 文字/分`、フィラーの数は `64 / 9.0 回/分` のように、スコアに続けて実測値を薄く添える） |
| 実施条件 | 区切り線の下に `対象企業：<企業名>`・`質問の強度：<楽々 / 標準 / 厳しめ / カスタム>`・`回答方式：<音声 / 文字入力>` を横並び |

**スコアの色分けとバーの長さは [共通仕様](../screen_common.md) 9章に従う。**

**話の速さまたはフィラーを計測できない場合は、該当行のスコアを `—`、実測値を `計測対象外` とし、バーの下地だけを表示する。** 総合スコアは、存在する基本項目から算出済みの値をそのまま表示する（[評価仕様](../../../評価仕様.md) 5章・6章）。

**チュートリアルの結果が直近だったときは、`対象企業：（企業なし）`・`質問の強度：—` とする。**

### 3.3 面接・練習を始める

| 項目 | 内容 |
|---|---|
| 見出し | `面接・練習を始める` |
| 説明 | `取り組むモードを選んで、設定へ進みます。` |
| 本番モードのボタン | `本番モードを始める` → `/practice/setup?mode=interview` で S-05 |
| 練習モードのボタン | `練習モードを始める` → `/practice/setup?mode=practice` で S-05 |

**モードは S-04 で確定し、S-05 では切り替えられない。**

### 3.4 チュートリアル

| 項目 | 内容 |
|---|---|
| 見出し | `チュートリアル` |
| 説明 | `「1分で自己紹介してください」の1問だけ。応募企業情報の登録なしで試せます。` |
| ボタン | `試してみる` → S-03 |

**登録件数にかかわらず常に表示する。**

### 3.5 応募企業情報 / 履歴

| カード | 見出し | 副文 | 導線 |
|---|---|---|---|
| 応募企業情報 | `応募企業情報` | `<件数> 件登録済み` | `一覧を見る` → S-06 |
| 履歴 | `履歴` | `<件数> 件の評価結果` | `履歴を見る` → S-16 |

## 4. 操作

| 操作 | 遷移先 |
|---|---|
| 「本番モードを始める」 | S-05（本番モード固定） |
| 「練習モードを始める」 | S-05（練習モード固定） |
| 「試してみる」 | S-03（S-08 の画面をチュートリアルとして開く） |
| 「詳細を見る」 | S-14（直近の評価結果を再表示） |
| 「一覧を見る」 | S-06 |
| 「履歴を見る」 | S-16 |

## 5. 状態

| 状態 | 表示 |
|---|---|
| 読み込み中 | 各カードの中身をスケルトンに置き換える（[共通仕様](../screen_common.md) 7.1） |
| **評価結果が0件** | 直近の評価結果のカードを、見出し `直近の評価結果` と `まだ結果がありません。練習かチュートリアルを始めると、ここに結果が出ます。` の表示に替える。**「詳細を見る」と最終実施日時は出さない** |
| **応募企業情報が0件** | 副文を `まだ登録がありません`、導線を `登録する`（→ S-07）に替える |
| 履歴が0件 | 副文を `0 件の評価結果` とし、導線はそのまま出す |
| 取得に失敗 | 失敗したカードの中に「読み込めませんでした」と「再読み込み」を出す（[共通仕様](../screen_common.md) 7.2）。**他のカードは表示を続ける** |

## 6. 呼ぶ API

| 契機 | API | 用途 |
|---|---|---|
| 画面表示 | `GET /evaluations` | 直近1件の内容と、履歴の件数 |
| 画面表示 | 応募企業情報 List | 登録件数 |

**評価結果の一覧は全件が返る**（[画面と API の対応](../screen_api_map.md)）。**直近1件の抽出と件数の算出は画面側で行う。**
