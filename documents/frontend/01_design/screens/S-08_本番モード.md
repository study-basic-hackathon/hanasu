# S-08 本番モード

## 1. 位置づけ

**AI 面接官とチャット形式の連続した会話として模擬面接を行う。本サービスの中心となる画面である。**

| 項目 | 内容 |
|---|---|
| 遷移元 | S-05（開始する）、S-04 / S-05（チュートリアルを試す → S-03 として開く） |
| 遷移先 | S-14 |
| ヘッダー | **専用**（[共通仕様](../screen_common.md) 5章） |
| コンテンツ幅 | 880px |
| 実装範囲 | 今回 |

**チュートリアル（S-03）はこの画面を流用する。** 差分は [9章](#9-チュートリアルs-03としての振る舞い) にまとめる。

### 前提

| # | 前提 | 出典 |
|---:|---|---|
| 1 | **サーバーは会話状態を持たない。** 会話履歴・質問の強度・企業 ID を毎ターン送る | [ADR-0008](../../../ADR/0008-会話用APIの構成.md) |
| 2 | **会話の終わりはサーバーが判断しない。** 画面がターン数の上限で打ち切る | 同上 |
| 3 | **音声は `MediaRecorder` で取得し、ターンごとに送る。サーバーは処理後に破棄する** | [ADR-0007](../../../ADR/0007-会話音声の取得と保存方式.md) |
| 4 | **無音の検出（VAD）と手動の停止を併用する** | 同上 |
| 5 | **話す速さ・フィラーの数はクライアントが算出する** | [ADR-0009](../../../ADR/0009-評価方式.md) / [評価仕様](../../../評価仕様.md) |

## 2. 画面の構成

**上から4つの帯に分ける。会話ログだけがスクロールする。**

| # | 領域 | 高さ | 内容 |
|---:|---|---|---|
| 1 | 専用ヘッダー | 60px | ロゴ + `本番モード` / 右に常時 `ホーム`、ターン上限前は `中断` |
| 2 | 実施条件の帯 | 52px | 左に実施条件、右にターン数の進捗 |
| 3 | 会話ログ | 可変 | 面接官と自分の発言を時系列に並べる |
| 4 | 回答の入力 | 可変 | 回答方式の切り替えと入力の操作 |

## 3. 実施条件の帯

| 位置 | 項目 | 表示 |
|---|---|---|
| 左 | 対象企業 | 企業名を**アクセント色のチップ**で示す |
| 左 | 質問の強度 | `質問の強度：<楽々 / 標準 / 厳しめ / カスタム>` |
| 左 | 回答方式 | `回答方式：<音声 / 文字入力>`。**切り替えるとこの表示も変わる** |
| 左 | 会話ログの文字起こし表示 | `フィラーなし / フィラーあり`。**初期値は `フィラーあり`** |
| 右 | ターン数 | `ターン <現在> / <上限>` |
| 右 | 進捗 | 上限と同じ数の小さなバーを並べ、**済んだターンをアクセント色で塗る** |

## 4. ターン

| 項目 | 値 |
|---|---|
| 1ターンの単位 | **面接官の質問1つと、それに対する自分の回答1つ** |
| 上限 | **8ターン** |
| 現在のターン | **回答を送るまでは、いま答えようとしているターンの番号**（最初の質問が出た時点で `ターン 1 / 8`） |
| 上限に達したとき | **8ターン目の回答を送り終えた時点で、確認を出さずに S-14 へ移る** |

**最初の質問はフロントエンドが持つ固定文字列とする**（[画面と API の対応](../screen_api_map.md)）。

## 5. 会話ログ

| 発言者 | 配置 | 見た目 | 補助情報 |
|---|---|---|---|
| 面接官 | 左 | アバター `面接`、白い吹き出し | 吹き出しの下に**時刻**と `読み上げる` |
| 自分（音声回答） | 右 | アバター `自分`、アクセント色の吹き出し | 吹き出しの下に `音声 <秒> 秒`・`話速 <文字/分>`・`フィラー <回数> 回`・**時刻**。続けて要改善の助言 |
| 自分（文字入力） | 右 | 同上 | 吹き出しの下に**時刻**だけを表示し、音声の計測値と助言は表示しない |

**新しい発言が増えたら、その発言が見えるところまで自動で下へ送る。**

**文字入力で答えたターンには、`音声 <秒> 秒`・話速・フィラー・ターン別の助言を出さない。** 評価の話速・フィラーには、必要な値を計測できた音声回答だけを使う（[評価仕様](../../../評価仕様.md) 3章）。

音声回答の吹き出しは、実施条件の帯で文字起こし表示を切り替える。

| 表示 | 吹き出しに使う値 |
|---|---|
| `フィラーなし` | `content`（`POST /interviews/stt` の `clean_transcript`） |
| `フィラーあり` | `raw_content`（同 API の `raw_transcript`）。`%えー%` などの `%` は表示せず、フィラー文字列だけをアクセント色の文字と薄い背景で強調する |

**`%` を外す処理と色付けは画面表示だけに適用する。** 切り替えは送信済みと以後の音声回答へ即時に反映し、API の再呼び出しや会話履歴の作り直しは行わない。文字入力の回答と面接官の発言は切り替えの影響を受けず、会話 API・評価 API へ渡す `%` 付きの値、フィラー数、話速の算出も変えない。表示設定は DB やブラウザへ保存しない。

### 5.1 音声回答のターン別フィードバック

音声回答の直後に、そのターンの話速とフィラー数を小さな補助情報として表示する。各値は [評価仕様](../../../評価仕様.md) の点数化基準を適用し、評価結果画面と同じ良好（アクセント色）・注意（警告色）・要改善（危険色）で表示する。フィラー数の表示はターン内の合計回数、色分けは毎分フィラー数を点数化した結果を使う。

| 指標 | 表示 | 要改善時の助言 |
|---|---|---|
| 話速 | `話速 <文字/分> 文字/分` | 速すぎて要改善の場合は `次はもう少しゆっくり話しましょう` |
| フィラー | `フィラー <回数> 回` | `次はフィラーを少なめにしましょう` |

**要改善の値と助言は危険色で表示する。** 音声回答で指標の計測値を取得できなかった場合は、その指標を `計測値なし` と表示し、点数化・色分け・助言を行わない。

### 5.2 「読み上げる」

**面接官の発言ごとに置き、押すとその発言を音声で再生する**（`POST /interviews/tts`）。面接官の読み上げ音声は、ブラウザ側で常に **1.2倍速** で再生する。
S-05 から読み上げ設定が渡されない、または不正な場合は、初期値として**読み上げる**を使う。S-05 で `読み上げない` を明示して開始した場合は、その設定を維持する。

| 状態 | 表示 |
|---|---|
| 通常 | `読み上げる` |
| 生成・再生中 | `停止する`。押すと再生をやめる |
| 失敗 | `読み上げられませんでした` を5秒表示して元に戻す |
| **TTS を使わないとき** | **ボタンそのものを出さない**（[画面と API の対応](../screen_api_map.md)） |

## 6. 回答の入力

**回答方式は会話の途中でも切り替えられる。** 切り替えても会話は続く。

### 6.1 音声で回答

| 状態 | 表示・操作 |
|---|---|
| **待機** | 録音の開始ボタン（丸）と `押して回答を録音します` |
| **録音中** | 開始ボタンが停止ボタン（危険色）に変わる。右上に `● 録音中 mm:ss`。中央に**入力レベルの波形**、右に `停止して送信` と `取り消す` |
| **無音が続いている** | 波形の下に `無音 <秒> 秒` のバッジと `あと <残り> 秒 静かなままだと自動で停止します` |
| **文字起こし中** | 入力の操作を押せなくし、`文字起こししています` |
| **面接官の応答待ち** | 会話ログの末尾に面接官の吹き出しを置き、`考えています` |

| 項目 | 値 |
|---|---|
| 無音での自動停止 | **3秒**。無音が3秒続いたら停止して送信する |
| 1回の録音の最長 | **3分**。超えたら自動で停止して送信する |
| 最短 | **1秒**。これに満たないまま停止したときは送らず、`録音が短すぎます。もう一度お試しください。` を出して待機に戻す |

| 操作 | 挙動 |
|---|---|
| 「停止して送信」 | 録音を止めて送る |
| 「取り消す」 | **録音を捨てて待機に戻す。** 会話ログは変わらない |

**マイクの使用許可は最初の録音のときに求める。拒否されたときの挙動は [共通仕様](../screen_common.md) 8章に従う。**

### 6.2 文字入力で回答

| 項目 | 内容 |
|---|---|
| 入力欄 | 複数行。プレースホルダ `回答を入力してください` |
| 送信 | `送信する`。**空のあいだは押せない** |
| 送信の近道 | Ctrl + Enter |

**文字入力のターンは文字起こしを経由せず、そのまま会話に送る**（[画面と API の対応](../screen_api_map.md)）。

## 7. 面接を中断する・ホームへ戻る

| 操作 | 挙動 |
|---|---|
| 回答0件で「ホーム」 | **確認を出さず、評価も実行せず**に会話を破棄して S-04 へ |
| 回答済みで「ホーム」 | **会話が失われ、評価されないことを確認する。** 取り消すと会話を保持して S-08 に留まり、続けると評価せずに会話を破棄して S-04 へ |
| 「中断」 | **確認を出す**（[共通仕様](../screen_common.md) 7.3）。続けると途中までの会話で評価を実行して S-14 へ |
| ターン上限に到達 | 会話を確認できる状態で停止する。`評価を見る`を選ぶと評価を実行して S-14 へ |

**評価は `POST /evaluations` を呼び、返った ID を持って S-14 へ移る。** 待ち合わせは S-14 が行う。

**評価 API へ渡す話速・フィラーは [評価仕様](../../../評価仕様.md) に従って算出する。** 文字入力と、対象指標に必要な値が欠測した音声回答は集計から除外する。対象音声がなければ、その項目を `scores` に含めない。

**「ホーム」は回答数やターン上限にかかわらず専用ヘッダーへ常に表示する。** 回答が1つもない状態では「中断」を押せない。押せない理由として `1問以上答えると評価できます。` を添える。ターン上限到達後は「中断」の代わりに画面下部の `評価を見る` を使う。

## 8. 状態とエラー

| 事象 | 挙動 |
|---|---|
| 文字起こしに失敗 | `聞き取れませんでした。もう一度お話しください。` を出し、**待機に戻す**。会話ログは変わらない |
| 面接官の応答に失敗 | 会話ログの末尾に `質問を作れませんでした。` と `もう一度試す` を出す。**送った回答は残す** |
| 評価の実行に失敗 | S-14 へ移らず、画面の下部に `評価を開始できませんでした。時間をおいてもう一度お試しください。` を出す。**会話は保持する** |
| 認証切れ（401） | S-01 へ移る。**会話は失われる**（[共通仕様](../screen_common.md) 6.2） |
| 再読み込み・離脱 | ブラウザの確認を出す。続行されたら会話は失われる（[共通仕様](../screen_common.md) 7.3） |

**画面の最下部に `この画面を離れると会話は失われます。評価は「中断」を押したあとに行われます。` を常に出す。** ターン上限到達後は操作名を `評価を見る` に替える。

### 8.1 録音した音声の扱い

**音声はブラウザの IndexedDB に一時保持する**（[ADR-0007](../../../ADR/0007-会話音声の取得と保存方式.md)）。

| 事象 | 扱い |
|---|---|
| 文字起こしが終わったターンの音声 | **話す速さの算出に使うため、面接が終わるまで残す** |
| 「取り消す」で捨てた録音 | **その場で消す** |
| 中断した・評価を実行した・ホームへ戻った | **すべて消す** |
| 画面を離れた・再読み込みした | **すべて消す。** 会話履歴が失われ、音声だけが残っても使い道がないためである |

**画面に音声の再生機能は持たない。**

## 9. チュートリアル（S-03）としての振る舞い

**同じ画面を使い、次の点だけを変える。**

| 項目 | 本番モード | チュートリアル |
|---|---|---|
| ヘッダーの画面名 | `本番モード` | `チュートリアル` |
| 対象企業 | 選んだ企業のチップ | **出さない。** 代わりに `チュートリアル` のチップ |
| 質問の強度 | 選んだ強度 | **出さない** |
| 最初の質問 | フロントの固定文字列 | **`1分で自己紹介してください。` に固定** |
| ターン数 | 8 | **1** |
| 会話 API | 呼ぶ | **呼ばない。** 1問で終わるため |
| 終わり方 | 「中断」、または上限到達後に「評価を見る」 | **回答を送った時点で評価へ進む** |
| 評価 | 企業 ID を添えて実行 | **企業 ID なしで実行**（[画面と API の対応](../screen_api_map.md)） |

**応募企業情報を1件も持っていなくても実行できる。**

## 10. 呼ぶ API

| 契機 | API |
|---|---|
| 画面表示 | `POST /interviews/start`（**任意**。当面はフロントの固定文字列） |
| 回答する（音声） | `POST /interviews/stt` → `POST /interviews/chat` |
| 回答する（文字入力） | `POST /interviews/chat` |
| 読み上げる | `POST /interviews/tts`（**任意**） |
| 中断する・評価を見る | `POST /evaluations` |
| ホームへ戻る | **呼ばない** |

**`POST /interviews/chat` には企業 ID・質問の強度・会話履歴を毎ターン送る。カスタム選択時は、S-05 から受け取った自然言語も `custom_question_strength` として毎ターン送る**（[画面と API の対応](../screen_api_map.md)）。
