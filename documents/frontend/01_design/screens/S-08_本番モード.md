# S-08 本番モード

## 1. 位置づけ

**AI 面接官とチャット形式の連続した会話として模擬面接を行う。本サービスの中心となる画面である。**

| 項目 | 内容 |
|---|---|
| 遷移元 | S-05（開始する）、S-04 / S-05（チュートリアルを試す → S-03 として開く） |
| 遷移先 | S-14 |
| ヘッダー | **専用**（[共通仕様](../screen_common.md) 5章） |
| コンテンツ幅 | 880px |
| 実装範囲 | 今回 |

**チュートリアル（S-03）はこの画面を流用する。** 差分は [9章](#9-チュートリアルs-03としての振る舞い) にまとめる。

### 前提

| # | 前提 | 出典 |
|---:|---|---|
| 1 | **サーバーは会話状態を持たない。** 会話履歴・質問の強度・企業 ID を毎ターン送る | [ADR-0008](../../../ADR/0008-会話用APIの構成.md) |
| 2 | **会話の終わりはサーバーが判断しない。** 画面がターン数の上限で打ち切る | 同上 |
| 3 | **音声は `MediaRecorder` で取得し、ターンごとに送る。サーバーは処理後に破棄する** | [ADR-0007](../../../ADR/0007-会話音声の取得と保存方式.md) |
| 4 | **無音の検出（VAD）と手動の停止を併用する** | 同上 |
| 5 | **話す速さ・フィラーの数はクライアントが算出する** | [ADR-0009](../../../ADR/0009-評価方式.md) |

## 2. 画面の構成

**上から4つの帯に分ける。会話ログだけがスクロールする。**

| # | 領域 | 高さ | 内容 |
|---:|---|---|---|
| 1 | 専用ヘッダー | 60px | ロゴ + `本番モード` / 右に `面接を終える` |
| 2 | 実施条件の帯 | 52px | 左に実施条件、右にターン数の進捗 |
| 3 | 会話ログ | 可変 | 面接官と自分の発言を時系列に並べる |
| 4 | 回答の入力 | 可変 | 回答方式の切り替えと入力の操作 |

## 3. 実施条件の帯

| 位置 | 項目 | 表示 |
|---|---|---|
| 左 | 対象企業 | 企業名を**アクセント色のチップ**で示す |
| 左 | 質問の強度 | `質問の強度：<楽々 / 標準 / 厳しめ>` |
| 左 | 回答方式 | `回答方式：<音声 / 文字入力>`。**切り替えるとこの表示も変わる** |
| 右 | ターン数 | `ターン <現在> / <上限>` |
| 右 | 進捗 | 上限と同じ数の小さなバーを並べ、**済んだターンをアクセント色で塗る** |

## 4. ターン

| 項目 | 値 |
|---|---|
| 1ターンの単位 | **面接官の質問1つと、それに対する自分の回答1つ** |
| 上限 | **8ターン** |
| 現在のターン | **回答を送るまでは、いま答えようとしているターンの番号**（最初の質問が出た時点で `ターン 1 / 8`） |
| 上限に達したとき | **8ターン目の回答を送り終えた時点で、確認を出さずに S-14 へ移る** |

**最初の質問はフロントエンドが持つ固定文字列とする**（[画面と API の対応](../screen_api_map.md)）。

## 5. 会話ログ

| 発言者 | 配置 | 見た目 | 補助情報 |
|---|---|---|---|
| 面接官 | 左 | アバター `面接`、白い吹き出し | 吹き出しの下に**時刻**と `読み上げる` |
| 自分 | 右 | アバター `自分`、アクセント色の吹き出し | 吹き出しの下に `音声 <秒> 秒`・`フィラー <回数>`・**時刻** |

**新しい発言が増えたら、その発言が見えるところまで自動で下へ送る。**

**文字入力で答えたターンには `音声 <秒> 秒` を出さない。** フィラーの数は文字起こし結果と文字入力のどちらからも数える。

### 5.1 「読み上げる」

**面接官の発言ごとに置き、押すとその発言を音声で再生する**（`POST /interviews/tts`）。

| 状態 | 表示 |
|---|---|
| 通常 | `読み上げる` |
| 生成・再生中 | `停止する`。押すと再生をやめる |
| 失敗 | `読み上げられませんでした` を5秒表示して元に戻す |
| **TTS を使わないとき** | **ボタンそのものを出さない**（[画面と API の対応](../screen_api_map.md)） |

## 6. 回答の入力

**回答方式は会話の途中でも切り替えられる。** 切り替えても会話は続く。

### 6.1 音声で回答

| 状態 | 表示・操作 |
|---|---|
| **待機** | 録音の開始ボタン（丸）と `押して回答を録音します` |
| **録音中** | 開始ボタンが停止ボタン（危険色）に変わる。右上に `● 録音中 mm:ss`。中央に**入力レベルの波形**、右に `停止して送信` と `取り消す` |
| **無音が続いている** | 波形の下に `無音 <秒> 秒` のバッジと `あと <残り> 秒 静かなままだと自動で停止します` |
| **文字起こし中** | 入力の操作を押せなくし、`文字起こししています` |
| **面接官の応答待ち** | 会話ログの末尾に面接官の吹き出しを置き、`考えています` |

| 項目 | 値 |
|---|---|
| 無音での自動停止 | **3秒**。無音が3秒続いたら停止して送信する |
| 1回の録音の最長 | **3分**。超えたら自動で停止して送信する |
| 最短 | **1秒**。これに満たないまま停止したときは送らず、`録音が短すぎます。もう一度お試しください。` を出して待機に戻す |

| 操作 | 挙動 |
|---|---|
| 「停止して送信」 | 録音を止めて送る |
| 「取り消す」 | **録音を捨てて待機に戻す。** 会話ログは変わらない |

**マイクの使用許可は最初の録音のときに求める。拒否されたときの挙動は [共通仕様](../screen_common.md) 8章に従う。**

### 6.2 文字入力で回答

| 項目 | 内容 |
|---|---|
| 入力欄 | 複数行。プレースホルダ `回答を入力してください` |
| 送信 | `送信する`。**空のあいだは押せない** |
| 送信の近道 | Ctrl + Enter |

**文字入力のターンは文字起こしを経由せず、そのまま会話に送る**（[画面と API の対応](../screen_api_map.md)）。

## 7. 面接を終える

| 操作 | 挙動 |
|---|---|
| 「面接を終える」 | **確認を出す**（[共通仕様](../screen_common.md) 7.3）。続けると評価を実行して S-14 へ |
| ターン上限に到達 | **確認を出さずに** 評価を実行して S-14 へ |

**評価は `POST /evaluations` を呼び、返った ID を持って S-14 へ移る。** 待ち合わせは S-14 が行う。

**回答が1つもない状態では「面接を終える」を押せない。** 押せない理由として `1問以上答えると評価できます。` を添える。

## 8. 状態とエラー

| 事象 | 挙動 |
|---|---|
| 文字起こしに失敗 | `聞き取れませんでした。もう一度お話しください。` を出し、**待機に戻す**。会話ログは変わらない |
| 面接官の応答に失敗 | 会話ログの末尾に `質問を作れませんでした。` と `もう一度試す` を出す。**送った回答は残す** |
| 評価の実行に失敗 | S-14 へ移らず、画面の下部に `評価を開始できませんでした。時間をおいてもう一度お試しください。` を出す。**会話は保持する** |
| 認証切れ（401） | S-01 へ移る。**会話は失われる**（[共通仕様](../screen_common.md) 6.2） |
| 再読み込み・離脱 | ブラウザの確認を出す。続行されたら会話は失われる（[共通仕様](../screen_common.md) 7.3） |

**画面の最下部に `この画面を離れると会話は失われます。評価は「面接を終える」を押したあとに行われます。` を常に出す。**

### 8.1 録音した音声の扱い

**音声はブラウザの IndexedDB に一時保持する**（[ADR-0007](../../../ADR/0007-会話音声の取得と保存方式.md)）。

| 事象 | 扱い |
|---|---|
| 文字起こしが終わったターンの音声 | **話す速さの算出に使うため、面接が終わるまで残す** |
| 「取り消す」で捨てた録音 | **その場で消す** |
| 面接を終えた（評価を実行した） | **すべて消す** |
| 画面を離れた・再読み込みした | **すべて消す。** 会話履歴が失われ、音声だけが残っても使い道がないためである |

**画面に音声の再生機能は持たない。**

## 9. チュートリアル（S-03）としての振る舞い

**同じ画面を使い、次の点だけを変える。**

| 項目 | 本番モード | チュートリアル |
|---|---|---|
| ヘッダーの画面名 | `本番モード` | `チュートリアル` |
| 対象企業 | 選んだ企業のチップ | **出さない。** 代わりに `チュートリアル` のチップ |
| 質問の強度 | 選んだ強度 | **出さない** |
| 最初の質問 | フロントの固定文字列 | **`1分で自己紹介してください。` に固定** |
| ターン数 | 8 | **1** |
| 会話 API | 呼ぶ | **呼ばない。** 1問で終わるため |
| 終わり方 | 「面接を終える」または上限到達 | **回答を送った時点で評価へ進む** |
| 評価 | 企業 ID を添えて実行 | **企業 ID なしで実行**（[画面と API の対応](../screen_api_map.md)） |

**応募企業情報を1件も持っていなくても実行できる。**

## 10. 呼ぶ API

| 契機 | API |
|---|---|
| 画面表示 | `POST /interviews/start`（**任意**。当面はフロントの固定文字列） |
| 回答する（音声） | `POST /interviews/stt` → `POST /interviews/chat` |
| 回答する（文字入力） | `POST /interviews/chat` |
| 読み上げる | `POST /interviews/tts`（**任意**） |
| 面接を終える | `POST /evaluations` |

**`POST /interviews/chat` には企業 ID・質問の強度・会話履歴を毎ターン送る**（[画面と API の対応](../screen_api_map.md)）。
