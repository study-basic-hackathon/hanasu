# S-16 履歴一覧

## 1. 位置づけ

**過去の練習の結果を一覧し、変化を振り返る。**

| 項目 | 内容 |
|---|---|
| 遷移元 | S-04（履歴を見る）、S-14（履歴）、ヘッダーのナビ「履歴」 |
| 遷移先 | S-14 |
| ヘッダー | グローバル（現在地: **履歴**） |
| コンテンツ幅 | 1080px |
| 実装範囲 | 今回 |

**評価結果の取得 API は全件を返す**（[画面と API の対応](../screen_api_map.md)）。**並び替えと絞り込みは画面側で行う。**

## 2. 画面の構成

| 領域 | 内容 |
|---|---|
| 見出し | 左に `履歴` と件数の説明、右に並び順 |
| 絞り込み | `表示する企業` と選択欄 |
| 一覧 | 表形式のカード |

説明文は `全 <件数> 件。チュートリアルの結果も含みます。`。**絞り込んでいるあいだは `<絞り込み後の件数> 件を表示しています（全 <全件数> 件）。` に替える。**

## 3. 並び順

| 選択肢 | 既定 |
|---|---|
| 新しい順 / 古い順 | **新しい順** |

**実施日時で並べる。** ページ送りは持たず、全件を縦に並べる。

## 4. 絞り込み

**対象企業で絞り込む。** 選択欄は次の順で並べる。

| # | 選択肢 | 件数 |
|---:|---|---|
| 1 | `すべての企業` | 全件 |
| 2〜 | 登録済みの企業名（**結果が1件以上あるものだけ**） | その企業の件数 |
| 最後 | `チュートリアル` | チュートリアルの件数 |

**各選択肢の右に件数を出す。** 既定は `すべての企業`。**チュートリアルは区切り線で分けて最後に置く。**

**削除済みの企業の結果も残る。** その企業は選択肢に `（削除済みの企業）` として出す。

**絞り込み中にその企業の最後の結果を削除したら、絞り込みを `すべての企業` に戻す。** 件数が0になった企業は選択肢から消えるため、選択したままにすると選択欄の表示と一覧が食い違う。

## 5. 一覧の項目

| 列 | 内容 |
|---|---|
| 実施日時 | `YYYY-MM-DD HH:mm` |
| 対象企業 / 種別 | 企業名を主、その下に `本番モード / 強度 <楽々 / 標準 / 厳しめ / カスタム>` |
| 総合スコア | 数値のみ |
| 項目別 | **話の速さ・フィラーの数・構成・内容の3本のバーを横に並べる。** 数値は出さない |
| 操作 | `開く` → S-14 と `削除`（[6.1](#61-削除)） |

**バーの色は [共通仕様](../screen_common.md) 9章に従う。** 並び順は常に「速さ / フィラー / 構成」で、列見出しにも `項目別（速さ / フィラー / 構成）` と示す。

**話の速さまたはフィラーを計測できない場合も、3本のバーの場所は維持する。** 該当項目はバーの下地だけを表示し、色の付いた部分を出さない（[評価仕様](../../../評価仕様.md) 6章）。

**チュートリアルの結果は、対象企業を `（企業なし）`、種別を `チュートリアル` とする。**

### 5.1 評価が終わっていない結果

| 状態 | 総合スコアの列 | 項目別の列 | 操作 |
|---|---|---|---|
| `processing` | `評価中` | 出さない | `開く`（S-14 の処理中を表示） |
| `failed` | `失敗` （危険色） | 出さない | `開く`（S-14 の失敗を表示） |

**削除はどの状態でもできる。** `processing` のまま止まった結果や `failed` の結果こそ消したくなるため、状態で操作を出し分けない。

## 6. 操作

| 操作 | 挙動 |
|---|---|
| 「開く」 | S-14 でその結果を表示する |
| 行のどこか | 「開く」と同じ。**ただし「削除」の上は除く** |
| 「削除」 | 確認を挟んでその結果を削除する（[6.1](#61-削除)） |
| 並び順の切り替え | 一覧を並べ替える。**API は呼び直さない** |
| 絞り込みの変更 | 一覧を絞り込む。**API は呼び直さない** |

### 6.1 削除

**不要になった結果を1件ずつ消す。** 削除した結果は元に戻せない。

| 段階 | 表示・挙動 |
|---|---|
| 「削除」を押す | **確認を出す。** 文面は `<実施日時> の <対象企業> の結果を削除します。元に戻せません。` と `削除する` / `取り消す`。チュートリアルの結果は対象企業を `チュートリアル` とする |
| 「取り消す」 | 何もせず確認を閉じる |
| 「削除する」 | `DELETE /evaluations/{evaluation_id}` を呼ぶ。**呼んでいるあいだは確認の両方のボタンを押せなくし、`削除する` を `削除しています` に替える**（[共通仕様](../screen_common.md) 7.1） |
| 成功 | **確認を閉じ、一覧からその行だけを除く。`GET /evaluations` は呼び直さない。** 一覧の上部に `<実施日時> の <対象企業> の結果を削除しました。` を出す |
| 失敗 | **確認を閉じ、**一覧の上部に赤字で1行出す（[共通仕様](../screen_common.md) 7.2）。**行は消さない**ので、同じ行でやり直せる |

**失敗の表示は確認を閉じてから出す。** 確認はモーダルのため、開いたままだと背後の1行が隠れて見えない。

**削除の結果は、次に「削除」を押したときに消す。** 一覧の取得に失敗したときの表示とは別に扱う。

## 7. 状態

| 状態 | 表示 |
|---|---|
| 読み込み中 | 一覧の行をスケルトンにする |
| **0件** | 表の代わりに `まだ結果がありません。練習かチュートリアルを始めると、ここに結果が並びます。` と `面接・練習を始める`（→ S-04）を出し、モード選択を促す |
| **絞り込んだ結果が0件** | `この企業の結果はまだありません。` を出す。**絞り込みの選択欄は残す** |
| 取得に失敗 | カードの中に「読み込めませんでした」と「再読み込み」を出す |

## 8. 呼ぶ API

| 契機 | API |
|---|---|
| 画面表示 | `GET /evaluations`（全件） |
| 結果を開く | `GET /evaluations/{evaluation_id}`（S-14 で呼ぶ） |
| 結果を削除する | `DELETE /evaluations/{evaluation_id}`（[API仕様.md](../../../backend/API仕様.md) 5.8） |

**「対象企業」と「項目別スコア」は一覧 API が返す**（[画面と API の対応](../screen_api_map.md) 6章）。**結果を開くまで詳細 API は呼ばない。**
