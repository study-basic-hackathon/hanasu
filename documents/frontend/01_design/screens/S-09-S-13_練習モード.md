# S-09〜S-13 練習モード（画面モック）

## 1. 位置づけ

**弱点ごとの個別トレーニングの入口と、そのサブ機能。ハッカソンでは画面のモックだけを作る**（[ユースケース](../../../ユースケース・ユーザーフロー.md) 2.2）。

| 項目 | 内容 |
|---|---|
| 遷移元 | S-05（練習モードを選んで開始） |
| 遷移先 | S-05（設定に戻る）、S-09 ⇄ S-10〜S-13 |
| ヘッダー | **専用**（[共通仕様](../screen_common.md) 5章） |
| 実装範囲 | **画面モックのみ** |

## 2. モックの範囲

| 項目 | 扱い |
|---|---|
| API | **呼ばない** |
| 録音 | **行わない。** マイクの使用許可も求めない |
| 評価 | **行わない。** S-14 へは移らない |
| 表示する数値 | **固定の見本の値を出す** |
| 操作 | **画面の切り替えだけが動く**（メニュー ⇄ サブ機能、設定に戻る） |

**「終える」は S-09 の練習メニューに戻る。** 評価しないため S-14 へは移らない。

## 3. S-09 練習メニュー

| 項目 | 内容 |
|---|---|
| ヘッダー | ロゴ + `練習モード` + `画面モック` のバッジ / 右に `設定に戻る`（→ S-05） |
| コンテンツ幅 | 1080px |
| 見出し | `練習メニュー` |
| 説明 | `弱点ごとの個別トレーニングです。この画面はモックで、評価は行われません。` |
| メニュー | 等幅2列で4枚のカード |

各カードは**画面 ID・名前・説明**を持つ。

| 画面ID | 名前 | 説明 |
|---|---|---|
| S-10 | 音読評価 | `提示された文章を読み上げ、話し方を評価します。` |
| S-11 | 滑舌練習 | `発音しにくい語句を読み上げます。` |
| S-12 | スピード測定 | `話す速さを測り、適正な速度との差を知ります。` |
| S-13 | 一問一答評価 | `志望動機など単一の質問に答え、内容を評価します。` |

## 4. サブ機能に共通するもの

**幅 708px の枠に収める。** 上部に高さ 48px の帯を持ち、左に `<画面ID> <名前>`、右に `別の練習を選ぶ`（→ S-09）を置く。

**各画面の下部に、録音の見本と `終える`（→ S-09）を置く。**

## 5. S-10 音読評価

| 項目 | 内容 |
|---|---|
| 課題文 | 面接の回答を想定した2文程度の文章 |
| 録音 | 開始ボタン、進捗のバー、`タップで録音を開始します（00:00 / 01:00）` |

## 6. S-11 滑舌練習

| 項目 | 内容 |
|---|---|
| 進捗 | `課題フレーズ <現在> / <全体>` |
| 課題フレーズ | 大きな文字で1つ |
| 指示 | `3 回続けて読み上げてください` |
| 録音 | 録音中の見本（停止ボタンと波形） |

## 7. S-12 スピード測定

| 項目 | 内容 |
|---|---|
| 課題文 | `課題文：` に続けて1文 |
| 測定値 | `<整数>` と `文字/分` |
| 適正域 | **適正域（280〜320 文字/分）を帯で示し、現在値の位置に印を置く** |
| 判定 | `適正域（280〜320）の中にあります` |
| 録音 | `測定中 mm:ss` |

**適正域は S-14 の話の速さと同じ値を使う**（[S-14 の詳細仕様](S-14_評価.md)）。

## 8. S-13 一問一答評価

| 項目 | 内容 |
|---|---|
| 質問 | `質問` のラベルと質問文1つ |
| 回答方式 | 音声 / 文字入力の切り替え |
| 入力欄 | プレースホルダ `回答を入力してください` |
| 操作 | `終える` / `回答する`。**`回答する` を押しても何も起きない** |
