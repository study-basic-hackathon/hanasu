# S-09〜S-13 練習モード

## 1. 位置づけ

**弱点ごとの個別トレーニングの入口と、そのサブ機能。** S-10 音読評価と S-12 スピード測定では録音した音声を一時評価し、結果を保存せずに繰り返し練習できる。

| 項目 | 内容 |
|---|---|
| 遷移元 | S-04（練習モードを始める） |
| 遷移先 | S-04（`/` でホームへ戻る）、S-09 ⇄ S-10・S-12・S-13 |
| ヘッダー | **専用**（[共通仕様](../screen_common.md) 5章） |
| 実装範囲 | S-09 のメニュー、S-10 の録音・一時評価、S-12 の話速測定、S-13 の一問一答評価 |

## 2. 練習結果の扱い

- 録音はブラウザの `MediaRecorder` で取得し、停止後に `POST /interviews/stt` へ送る
- 音声、文字起こし、評価結果は画面内のメモリだけに保持し、データベースへ保存しない
- 評価 API は呼ばず、S-14 へ遷移しない
- 「終える」と「別の練習を選ぶ」は S-09 へ戻る
- 再練習、画面遷移、アンマウントでは録音・処理中のリクエスト・一時結果を破棄し、利用中の `MediaStream` を停止する

## 3. S-09 練習メニュー

| 項目 | 内容 |
|---|---|
| ヘッダー | ロゴ + `練習モード` / 右に `ホームへ戻る`（→ S-04） |
| コンテンツ幅 | 1080px |
| 見出し | `練習メニュー` |
| 説明 | `弱点ごとの個別トレーニングです。取り組む練習を選んでください。` |
| メニュー | 等幅3列で3枚のカード |

各カードは**画面 ID・名前・説明**を持つ。

| 画面ID | 名前 | 説明 |
|---|---|---|
| S-10 | 音読評価 | `提示された文章を読み上げ、話し方を評価します。` |
| S-12 | スピード測定 | `話す速さを測り、適正な速度との差を知ります。` |
| S-13 | 一問一答評価 | `志望動機など単一の質問に答え、話し方を確認します。` |

S-11 滑舌練習はメニューに表示しない。

## 4. サブ機能に共通するもの

**幅 708px の枠に収める。** 上部に高さ 48px の帯を持ち、左に `<画面ID> <名前>`、右に `別の練習を選ぶ`（→ S-09）を置く。

録音から文字起こしまでの状態管理は、S-10・S-12・S-13 で同じ共通処理を使う。共通処理は次を担う。

1. マイク使用許可の確認と録音開始・停止
2. 画面ごとの制限時間による自動停止
3. `POST /interviews/stt` の呼び出しと処理中表示
4. 失敗時の同じ音声の再送、または再録音
5. 再練習・画面離脱時の録音、リクエスト、一時結果の破棄

### 4.1 録音・処理の状態

| 状態 | 表示・操作 |
|---|---|
| 開始前 | 録音開始ボタンと制限時間を表示する |
| マイク確認中 | `マイクの使用許可を確認しています` と表示し、重複操作を受け付けない |
| 録音中 | 経過時間、上限、進捗バー、停止ボタンを表示する |
| 処理中 | `処理中です。文字起こしと評価を計算しています` と表示し、重複操作を受け付けない |
| 完了 | 画面ごとの一時評価と再練習操作を表示する |
| 失敗 | エラーメッセージと再試行操作を表示する |

### 4.2 エラー

| 条件 | 表示・復帰方法 |
|---|---|
| マイク非対応・権限拒否・録音開始失敗 | マイクを使用できない旨を表示し、録音開始を再試行できる状態へ戻す |
| 1秒未満で停止 | 録音が短すぎる旨を表示し、録音開始を再試行できる状態へ戻す |
| 文字起こし失敗 | 失敗を表示し、保持中の同じ音声を再送するか、破棄して再録音できる |
| 認証切れ | 再サインインが必要な旨を表示する |
| データ超過 | 録音し直す旨を表示する |

## 5. S-10 音読評価

### 5.1 課題と録音

| 項目 | 内容 |
|---|---|
| 課題文 | 面接の回答を想定した固定の2文 |
| 録音開始 | 課題文を見たまま開始できる |
| 手動停止 | 録音ボタンをもう一度押して停止する |
| 制限時間 | 1分。到達時は自動停止し、その時点の音声を文字起こしする |
| 経過表示 | `mm:ss / 01:00` と進捗バー |

### 5.2 一時評価

`POST /interviews/stt` が返す値から、次の2項目だけを表示する。課題文との一致率、発音、滑舌は評価しない。

| 項目 | 値 | 表示単位 | 判定 |
|---|---|---|---|
| 話速 | `chars_per_min` | `文字/分`（整数表示） | `scoreSpeakingSpeed` と `SPEAKING_SPEED_RANGE` に基づく色と短いコメント |
| フィラー | `filler_count_per_min` | `回/分`（小数第1位表示） | `scoreFillerRate` に基づく色と短いコメント |

色は共通の3段階（良好・注意・要改善）を使う。話速のコメントは適正域より遅い・適正・速いを区別し、フィラーのコメントはフィラーを抑えられているか、間を取る改善が必要かを示す。

結果には `結果はこの画面だけに表示され、保存されません` と表示する。

### 5.3 結果後の操作

| 操作 | 振る舞い |
|---|---|
| `もう一度練習する` | 録音、経過時間、文字起こし、一時評価を初期化して開始前へ戻る |
| `終える` | 一時データを破棄して S-09 へ戻る |

## 6. S-11 滑舌練習

メニューには表示せず、実装対象としない。

## 7. S-12 スピード測定

### 7.1 課題と録音

| 項目 | 内容 |
|---|---|
| 課題文 | `課題文：` に続けて1文 |
| 録音開始 | 課題文を見たまま開始できる |
| 手動停止 | 録音ボタンをもう一度押して停止する |
| 制限時間 | 1分。到達時は自動停止し、その時点の音声を文字起こしする |
| 経過表示 | `mm:ss / 01:00` と進捗バー |

### 7.2 一時評価

`POST /interviews/stt` が返す `chars_per_min` だけを、整数と `文字/分` で表示する。フィラー、発音、滑舌、課題文との一致率は表示・評価しない。

- **適正域は [評価仕様](../../../評価仕様.md) の話速100点域と同じ値（240〜260 文字/分）を使う**（[S-14 の詳細仕様](S-14_評価.md)）。帯と現在値の印で比較する
- `scoreSpeakingSpeed` と `SPEAKING_SPEED_RANGE` に基づく色とともに、遅い・適正・速いを区別する短いコメントを表示する
- 結果には `結果はこの画面だけに表示され、保存されません` と表示する

### 7.3 結果後の操作

| 操作 | 振る舞い |
|---|---|
| `もう一度測定する` | 録音、経過時間、文字起こし、一時評価を初期化して開始前へ戻る |
| `終える` | 一時データを破棄して S-09 へ戻る |

## 8. S-13 一問一答評価

固定の見本質問に音声で回答し、話し方の基本指標だけを確認する。回答内容の正しさ、質問との関連性、文章構成、語彙は評価しない。質問生成 API・会話 API・評価 API は呼ばず、テキスト回答にも切り替えない。

### 8.1 質問と録音

| 項目 | 内容 |
|---|---|
| 質問 | `質問` のラベルと `なぜ当社を志望されたのですか。` |
| 回答方式 | 音声回答のみ |
| 録音開始・停止 | 質問を見たまま開始でき、録音ボタンをもう一度押すと停止する |
| 制限時間 | 1分。到達時は自動停止し、その時点の音声を文字起こしする |
| 経過表示 | `mm:ss / 01:00` と進捗バー |

録音・文字起こし中の表示、エラー、再試行、画面離脱時の破棄は 4章に従う。

### 8.2 一時評価と結果後の操作

`POST /interviews/stt` が返す値から、次の2項目だけを表示する。話速は `chars_per_min` を整数と `文字/分` で、フィラーは `filler_count_per_min` を小数第1位と `回/分` で表示する。各項目は `scoreSpeakingSpeed`、`scoreFillerRate`、`SPEAKING_SPEED_RANGE` に基づく共通の3段階の色と短い改善コメントを使う。

結果には `結果はこの画面だけに表示され、保存されません` と表示する。

| 操作 | 振る舞い |
|---|---|
| `もう一度回答する` | 録音、経過時間、文字起こし、一時評価を初期化して開始前へ戻る |
| `終える` | 一時データを破棄して S-09 へ戻る |

## 9. 実施しないこと

- 課題文と文字起こし結果の一致率、発音、滑舌の評価
- 練習結果を保存する API、評価 API、データベース保存
- 総合評価画面（S-14）への遷移
- 課題文を管理・ランダム配信する仕組み
