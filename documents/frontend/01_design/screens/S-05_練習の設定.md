# S-05 練習の設定

## 1. 位置づけ

**練習を始める前に、モード・回答方式・質問の強度・対象企業を1画面でまとめて決める。**

| 項目 | 内容 |
|---|---|
| 遷移元 | S-04（練習を始める）、S-07（保存 / 取り消し）、S-09（設定に戻る）、S-14（再挑戦）、ヘッダーのナビ「練習の設定」 |
| 遷移先 | S-08、S-09、S-07、S-03 |
| ヘッダー | グローバル（現在地: **練習の設定**） |
| コンテンツ幅 | 960px |
| 実装範囲 | 今回 |

**選んだ内容はサーバーに保存しない。** S-08 へそのまま引き渡す（[画面と API の対応](../screen_api_map.md)）。

## 2. 画面の構成

上から順に置く。

| # | 領域 | 内容 |
|---:|---|---|
| 1 | 見出し | パンくず `ホーム / 練習` と見出し `練習の設定` |
| 2 | モード | 本番モード / 練習モードの2択 |
| 3 | 回答方式・質問の強度 | 等幅の2カラム |
| 4 | 対象企業 | 登録済みの応募企業情報から1つ選ぶ |
| 5 | 開始 | 左に「先にチュートリアルを試す」、右に注記と「開始する」 |

## 3. 設定項目

| # | 項目 | 選択肢 | 既定値 | 備考 |
|---:|---|---|---|---|
| 1 | モード | 本番モード / 練習モード | **本番モード** | 練習モードには `モック` のバッジを付ける |
| 2 | 回答方式 | 音声 / 文字入力 | **音声** | 2つを連結したトグルで示す |
| 3 | 質問の強度 | 楽々 / 標準 / 厳しめ | **標準** | 横に並んだ3つのボタン |
| 4 | 対象企業 | 登録済みの応募企業情報 | **未選択** | 単一選択 |

**選択中の項目はアクセント色の枠と淡い背景で示す**（[共通仕様](../screen_common.md) 11章）。

### 3.1 各項目の説明文

| 項目 | 説明文 |
|---|---|
| 本番モード | `AI 面接官と連続した会話で模擬面接を行う` |
| 練習モード | `弱点ごとの個別トレーニングを選ぶ` |
| 回答方式 | `音声を選ぶとマイクの使用許可を求めます。` |
| 質問の強度 | `深掘りの度合いが変わります。強度は毎ターン面接官に伝わります。` |

**マイクの使用許可はこの画面では求めない**（[共通仕様](../screen_common.md) 8章）。

### 3.2 対象企業の一覧

| 項目 | 内容 |
|---|---|
| 見出し | `対象企業` |
| 追加の導線 | `企業を追加` → S-07 |
| 各行 | 選択の丸、企業名、その下に `<登録済みの情報>`、右端に `編集` → S-07 |
| 登録済みの情報 | [S-06](S-06_応募企業情報_一覧.md) 3.1 の区分を `/` で連ねる（例: `募集要項 / 志望動機 / 経歴`）。**該当する情報がなければ `未入力` を出す** |

## 4. 操作

| 操作 | 挙動 |
|---|---|
| 各項目を選ぶ | 選択状態を切り替える。**画面遷移はしない** |
| 「企業を追加」 | S-07 を新規登録として開く。**戻り先は S-05** |
| 行の「編集」 | S-07 をその企業の編集として開く。**戻り先は S-05** |
| 「先にチュートリアルを試す」 | S-03（S-08 をチュートリアルとして開く） |
| 「開始する」 | 本番モードなら S-08、練習モードなら S-09 |

**「先にチュートリアルを試す」は登録件数にかかわらず常に出す。**

## 5. 開始の条件

| モード | 条件 |
|---|---|
| 本番モード | **対象企業が1つ選ばれていること。** 選ばれていなければ「開始する」を押せなくする |
| 練習モード | **条件なし。** 対象企業を選ばなくても開始できる |

**練習モードを選んでいるあいだ、対象企業の一覧は選べない状態にする**（薄く表示し、選択の操作を受け付けない）。練習モードは応募企業情報を使わないためである。

「開始する」の左に `上限 <N> ターンで自動終了します` を出す。**N は S-08 のターン数の上限**（[S-08 の詳細仕様](S-08_本番モード.md)）。**練習モードを選んでいるあいだは出さない。**

## 6. 状態

| 状態 | 表示 |
|---|---|
| 読み込み中 | 対象企業のカードの中身をスケルトンにする。他の項目は操作できる |
| **応募企業情報が0件** | 一覧の代わりに `登録された企業がありません。企業を追加すると、その内容をもとに質問が作られます。` と `企業を追加` を出す。**本番モードでは「開始する」を押せない** |
| 取得に失敗 | 対象企業のカードの中に「読み込めませんでした」と「再読み込み」を出す |

## 7. 呼ぶ API

| 契機 | API |
|---|---|
| 画面表示 | 応募企業情報 List |
| 「開始する」 | **なし。** 選択内容を S-08 / S-09 へ引き渡す |
