# S-05 練習の設定

## 1. 位置づけ

**S-04 で選んだモードを固定し、開始前の条件を1画面でまとめて決める。**

| 項目 | 内容 |
|---|---|
| 遷移元 | S-04（本番モード / 練習モードを始める）、S-07（保存 / 取り消し）、S-09（設定に戻る）、S-14（再挑戦） |
| 遷移先 | S-08、S-09、S-07、S-03 |
| ヘッダー | グローバル（ナビは共通仕様に従う） |
| コンテンツ幅 | 960px |
| 実装範囲 | 今回 |

**選んだ内容はサーバーに保存しない。** 本番モードの設定は S-08 へそのまま引き渡し、練習モードでは S-09 へ進む（[画面と API の対応](../screen_api_map.md)）。

| URL | 固定するモード |
|---|---|
| `/practice/setup?mode=interview` | 本番モード |
| `/practice/setup?mode=practice` | 練習モード |

**`mode` がない、複数ある、または上記以外の値なら S-04 へ戻し、モードを選び直してもらう。**

## 2. 画面の構成

上から順に置く。

| # | 領域 | 内容 |
|---:|---|---|
| 1 | 見出し | パンくずと、固定したモードに応じた `本番モードの設定` / `練習モードの設定` |
| 2 | 回答方式・質問の強度 | 等幅の2カラム |
| 3 | 最大ターン数・読み上げモード | 本番モードだけに等幅の2カラムで表示 |
| 4 | 対象企業 | 登録済みの応募企業情報から1つ選ぶ |
| 5 | 開始 | 左に「先にチュートリアルを試す」、右に注記とモード別の開始ボタン |

## 3. 設定項目

| # | 項目 | 選択肢 | 既定値 | 備考 |
|---:|---|---|---|---|
| 1 | 回答方式 | 音声 / 文字入力 | **音声** | 2つを連結したトグルで示す |
| 2 | 質問の強度 | 楽々 / 標準 / 厳しめ / カスタム | **標準** | 横に並んだ4つのボタン |
| 3 | 最大ターン数 | 1〜25の整数 | **10** | 本番モードだけに表示する |
| 4 | 読み上げモード | 読み上げる / 読み上げない | **読み上げる** | 本番モードだけに表示し、面接中も変更できる |
| 5 | 対象企業 | 登録済みの応募企業情報 | **未選択** | 単一選択 |

**選択中の項目はアクセント色の枠と淡い背景で示す**（[共通仕様](../screen_common.md) 11章）。

`カスタム` を選んだときだけ、質問の厳しさや進め方を自然言語で入力する複数行の入力欄を表示する。入力は前後の空白を除いて1〜500文字を必須とし、現在の文字数を `<N>/500文字` で示す。空白のみの場合は `カスタムの質問強度を入力してください。`、500文字を超えた場合は `カスタムの質問強度は500文字以内で入力してください。` を表示する。別の強度へ切り替えて入力欄を隠しても、入力内容はこの画面にいる間は保持する。

### 3.1 各項目の説明文

| 項目 | 説明文 |
|---|---|
| 回答方式 | `音声を選ぶとマイクの使用許可を求めます。` |
| 質問の強度 | `深掘りの度合いが変わります。強度は毎ターン面接官に伝わります。` |
| 最大ターン数 | `1〜25ターンの範囲で設定できます。` |
| 読み上げモード | `面接中にも読み上げモードを変更できます。` |

**マイクの使用許可はこの画面では求めない**（[共通仕様](../screen_common.md) 8章）。

### 3.2 対象企業の一覧

| 項目 | 内容 |
|---|---|
| 見出し | `対象企業` |
| 追加の導線 | `企業を追加` → S-07 |
| 各行 | 選択の丸、企業名、その下に `<登録済みの情報>`、右端に `編集` → S-07 |
| 登録済みの情報 | [S-06](S-06_応募企業情報_一覧.md) 3.1 の区分を `/` で連ねる（例: `募集要項 / 志望動機 / 経歴`）。**該当する情報がなければ `未入力` を出す** |

## 4. 操作

| 操作 | 挙動 |
|---|---|
| 各設定項目を選ぶ | 選択状態を切り替える。**画面遷移はせず、モードは切り替えられない** |
| 「企業を追加」 | S-07 を新規登録として開く。**戻り先は同じモードの S-05** |
| 行の「編集」 | S-07 をその企業の編集として開く。**戻り先は同じモードの S-05** |
| 「先にチュートリアルを試す」 | S-03（S-08 をチュートリアルとして開く） |
| 「本番モードを始める」 | 本番モード固定のとき S-08 |
| 「練習モードを始める」 | 練習モード固定のとき S-09 |

**「先にチュートリアルを試す」は登録件数にかかわらず常に出す。**

## 5. 開始の条件

| モード | 条件 |
|---|---|
| 本番モード | **対象企業が1つ選ばれ、最大ターン数が1〜25の整数であり、カスタム選択時は自然言語が1〜500文字であること。** 満たさなければ「本番モードを始める」を押せなくする |
| 練習モード | **カスタム選択時の自然言語が1〜500文字であること。** 対象企業を選ばなくても開始できる |

**練習モード固定の画面では、対象企業の一覧を選べない状態にする**（薄く表示し、選択の操作を受け付けない）。練習モードは応募企業情報を使わないためである。

「本番モードを始める」の左に `上限 <N> ターンで自動終了します` を出す。**N は S-08 のターン数の上限**（[S-08 の詳細仕様](S-08_本番モード.md)）。**練習モード固定の画面では出さない。**

## 6. 状態

| 状態 | 表示 |
|---|---|
| 読み込み中 | 対象企業のカードの中身をスケルトンにする。他の項目は操作できる |
| **応募企業情報が0件** | 一覧の代わりに `登録された企業がありません。企業を追加すると、その内容をもとに質問が作られます。` と `企業を追加` を出す。**本番モードでは「本番モードを始める」を押せない** |
| 取得に失敗 | 対象企業のカードの中に「読み込めませんでした」と「再読み込み」を出す |
| **モードが未指定 / 複数 / 不正** | S-04 へ戻し、本番モード・練習モードの選択を促す |

## 7. 呼ぶ API

| 契機 | API |
|---|---|
| 画面表示 | 応募企業情報 List |
| モード別の開始ボタン | **なし。** 選択内容を S-08 / S-09 へ引き渡す。S-08 にはカスタムの自然言語も渡す |
