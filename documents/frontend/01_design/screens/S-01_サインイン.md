# S-01 サインイン

## 1. 位置づけ

**固定のアカウントで認証する。本サービスの唯一の入口である。**

| 項目 | 内容 |
|---|---|
| 遷移元 | なし（直接開く）、または未認証・認証切れによる転送（[共通仕様](../screen_common.md) 6章） |
| 遷移先 | S-04 ホーム |
| ヘッダー | **持たない** |
| 実装範囲 | 今回 |

**会員登録・パスワード再設定の導線を持たない**（[ADR-0011](../../../ADR/0011-会員登録と利用アカウント.md)）。

## 2. 画面の構成

**画面中央にひとまとまりを置く**（幅 420px）。上からサービス名・カード・注記の順。

| 領域 | 内容 |
|---|---|
| サービス名 | 「hanasu」と、その下に「AI 面接官と話して、話し方を測る」 |
| カード | ID・パスワードの入力欄と「サインイン」ボタン |
| 注記 | カードの下部、区切り線の下 |

## 3. 表示項目

| # | 項目 | 内容 |
|---:|---|---|
| 1 | サービス名 | `hanasu` |
| 2 | 説明文 | `AI 面接官と話して、話し方を測る` |
| 3 | ID のラベル | `ID` |
| 4 | パスワードのラベル | `パスワード` |
| 5 | 送信ボタン | `サインイン` |
| 6 | 注記 | `配布された ID とパスワードでサインインしてください。会員登録・パスワード再設定は用意していません。` |

## 4. 入力

| 項目 | 種類 | 必須 | 備考 |
|---|---|---|---|
| ID | 1行テキスト | ○ | 前後の空白は取り除いて送る |
| パスワード | パスワード | ○ | 伏せ字で表示する。表示切り替えは持たない |

### バリデーション

| 条件 | 挙動 |
|---|---|
| ID またはパスワードが空 | **「サインイン」を押せなくする。** エラー文は出さない |
| 両方が入っている | 「サインイン」を押せる |

**入力の形式（文字種・長さ）は検査しない。** 正否はサーバーが決める。

## 5. 操作

| 操作 | 挙動 |
|---|---|
| 「サインイン」を押す | `POST /token` を呼ぶ。成功したらトークンを保持して S-04 へ |
| パスワード欄で Enter | 「サインイン」と同じ |

## 6. 状態

| 状態 | 表示 |
|---|---|
| 通常 | 3章のとおり |
| 送信中 | **「サインイン」を押せなくし、ラベルを `サインインしています` に替える。** 入力欄も編集できなくする |
| **認証失敗（401）** | カード内のボタンの上に赤字で `ID またはパスワードが違います。` **入力した ID は残し、パスワードだけを消す** |
| **通信・サーバーエラー** | 同じ位置に赤字で `サインインできませんでした。時間をおいてもう一度お試しください。` **入力は残す** |
| 認証切れによる転送 | 説明文の下に `サインインの有効期限が切れました。もう一度サインインしてください。` |

## 7. 呼ぶ API

| 契機 | API |
|---|---|
| サインイン | `POST /token` |

**入出力は [API仕様.md](../../../backend/API仕様.md) が正本である。**
