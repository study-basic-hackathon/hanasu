# 技術スタック

## 音声認識

- AmiVoice（[ADR-0010](ADR/0010-音声認識とLLMの基盤選定.md)）
  - `keepFillerToken=1` を付与し、フィラーを保持したまま文字起こしする
  - **商用の外部 API。** アカウント・課金・API キーの管理が要る

## インフラ

- AWS
  - S3(terraformのstate管理用)
  - VPC
  - ALB
  - ECR
  - ECS
  - RDS
    - 応募情報（企業情報 + 志望動機 + 経歴を1レコードで持つ）
    - 評価結果
    - **会話履歴・音声・文字起こしは保存しない**（[ADR-0007](ADR/0007-会話音声の取得と保存方式.md) / [ADR-0009](ADR/0009-評価方式.md)）
  - CloudWatch Logs
  - Bedrock
    - 会話（次の質問の生成）と評価の定性項目に使う（[ADR-0010](ADR/0010-音声認識とLLMの基盤選定.md)）
    - **アプリから呼ぶには ECS タスクロールの新設が要る**（現状は実行ロールのみ）
  - Amplify Hosting
    - フロントエンドのデプロイ先（[ADR-0012](ADR/0012-フロントエンドデプロイ先.md)。[ADR-0001](ADR/0001-フロントエンド実行環境.md) の Vercel から変更）
- Terraform(IaC)
- GitHub Actions(CI/CD)

以下は現状想定では使わない

- Amazon Cognito
  - 認証は簡易的。**会員登録は実装せず、固定の ID / パスワード1組を使う**（[ADR-0011](ADR/0011-会員登録と利用アカウント.md)）
- S3
  - 音声データ
  - **音声はブラウザの IndexedDB に一時保持し、サーバーは処理後に破棄するため不要**（[ADR-0007](ADR/0007-会話音声の取得と保存方式.md)）
- Chime SDK
  - **1対1かつ相手が AI のため、代替不能な機能がない。** 音声はブラウザの `MediaRecorder` で取得し、ターンごとに HTTP で送る（[ADR-0007](ADR/0007-会話音声の取得と保存方式.md)）
- NAT Gateway
  - コスト削減のためECSタスクはPublicサブネットに直接配置
    - ただしaws_security_group.ecs_taskでaws_security_group.albからのlocal.container_port宛インバウンドのみ許可しており、外部から直接アクセスはできない

## フロント

- Typescript
- Next.js 16.3（App Router）
  - デプロイ先：AWS Amplify Hosting（[ADR-0012](ADR/0012-フロントエンドデプロイ先.md)。[ADR-0001](ADR/0001-フロントエンド実行環境.md) の Vercel を置き換え）
  - 初期構成は create-next-app の推奨デフォルト + `src/`（[ADR-0004](ADR/0004-Nextjsプロジェクト初期構成.md)）
  - 開発バンドラは Turbopack（[ADR-0005](ADR/0005-開発バンドラ.md)）
- Node.js 24.x（[ADR-0002](ADR/0002-Nodeバージョン.md)）
  - ローカル（Docker）は `package.json` の `engines.node` とイメージタグで固定する
  - Amplify 側は別途明示指定が必要（[ADR-0012](ADR/0012-フロントエンドデプロイ先.md) の再検討結果。指定方法の確定は構築時）
- パッケージマネージャ：npm（[ADR-0003](ADR/0003-パッケージマネージャ.md)）
- Linter：ESLint（[ADR-0004](ADR/0004-Nextjsプロジェクト初期構成.md)）
- スタイル：**Tailwind CSS のみ。** shadcn/ui 等のコンポーネント集・ヘッドレス UI・チャートライブラリは追加しない（[ADR-0014](ADR/0014-UI技術方針.md)）
- ローカル開発：Docker（ベースイメージ `node:24-bookworm-slim`、[ADR-0006](ADR/0006-開発用Dockerベースイメージ.md)）
